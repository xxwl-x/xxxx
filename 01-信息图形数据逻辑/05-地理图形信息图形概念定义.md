# 05｜地理图形信息图形：概念定义

## 定义
以真实或明确界定的空间位置、区域、距离、方位、邻接或流动关系组织信息，使读者理解“在哪里、如何分布、彼此如何连接”。仅仅画出地图轮廓或地点图标，不足以构成地理逻辑。

## A｜基本数据逻辑
点位数据将对象 ID 与坐标关联，表达位置与分布；区域数据将区域 ID、边界几何与属性关联，表达区域差异、包含或邻接；路径/流向数据将起点、终点、路径与流量字段关联，表达移动、联系或运输。空间参照不可任意替换；需记录坐标参考系、地理边界、统计时期和空间单位。地理信息可叠加时间或分类，但主归属取决于作品主要回答的问题。

## B｜统计图形与计算方式
数据处理包括地理编码、坐标转换、空间连接、距离、邻接、区域聚合、密度与比率计算。常见图形包括点位地图、分级设色地图、比例符号地图、路线图、流向/OD 图、格网地图和空间小倍数图。不同面积或人口规模的区域不可只比较原始总量而忽略分母；密度/比率必须标明分母与单位。地图投影可能改变面积、距离或形状；点大小、线宽和颜色值需有明确映射与图例。未经计算验证的模糊热区效果，不应声称为真实空间密度。

## C｜视觉编码
| 通道 | 主要作用 | 编码注意 |
|---|---|---|
| 点 | 城市、设施、事件位置 | 坐标与定位来源可追溯 |
| 线 | 边界、路径、流向 | 区分行政边界、交通线和数据流 |
| 面 | 区域、覆盖、密度 | 分类色与连续色阶区分，注明单位 |
| 体 | 地形、建筑、地标 | 高度仅在有数据映射时表达数值 |
| 符号 | 设施类型、地点身份 | 图例完整，避免符号重叠误读 |
| 色彩 | 类别、强度、正负差异 | 使用有序/发散色阶并标注范围 |
| 文字 | 地名、方向、比例尺、来源 | 说明时期和空间口径 |

优先级：空间定位准确 → 数据量纲与色标 → 符号可读 → 装饰。

## D｜数据/信息架构
点位表可含 object_id、name、longitude、latitude、value、period；区域表可含 region_id、geometry/source_id、value、denominator、period；路径表可含 origin_id、destination_id、route_id、flow_value。坐标需注明 CRS；区域统计需说明行政区划版本和边界口径。字段示例不代表真实坐标或观测值。

## E｜视觉叙事架构
整体空间范围 → 主要分布格局 → 局部热点/路径 → 区域差异解释 → 回到整体。路线叙事可以使用起点、途经点和终点，但箭头不自动代表时间因果。

## 分类核验
如果移除真实空间位置、区域几何或空间关系，作品的核心信息便无法成立，地理图形逻辑较可能是主归属。

## CASE-0017｜案例观察：道路网络双变量专题地图

[Arteries of the city｜完整 A—E 分析](../02-信息图形类型案例/07-地标型-Location/案例/CASE-0017-Arteries-of-the-city/分析.md)

本案例以香港道路网络为不可替代的空间骨架，将2011年道路日均车辆量编码为道路带宽度，将相较上一年度的百分比变化编码为蓝—浅色—红的发散色彩。左下角车辆登记表另以2011年数量和相对2000年的变化作辅助背景。它体现了地理图型中的**路径/网络数据＋双变量线性编码**：线宽表达绝对量，颜色表达变化率。道路空间拓扑是主组织逻辑，年份仅作为统计时期与比较基准，因此不属于时间轴型。注意主地图和车辆登记表的时间比较基准不同，不能混用。
