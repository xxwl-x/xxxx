# 04｜主题信息图形设计流程

本目录用于把一个主题从研究问题转化为可交付的信息图形。此流程是项目工作模板，不代表空白阶段已完成研究。

## 工作流程
| 阶段 | 关键任务 | 主要输出 |
|---|---|---|
| 01 前期调研 | 明确主题、受众、使用场景、问题与资料边界 | 调研简报、问题清单 |
| 02 主题内容分析 | 拆解对象、核心问题、基础逻辑与表现形式 | 内容结构、分类判断 |
| 03 数据搜集 | 搜集可追溯的原始数据、文献和官方资料 | 来源清单、原始资料 |
| 04 基础数据集构建 | 清洗、统一字段、记录口径和缺失值 | CSV/表格、数据字典 |
| 05 叙事框架搭建 | 从数据关系中提炼命题、选择字段、组织阅读路径 | 叙事大纲、模块结构 |
| 06 视觉编码 | 决定统计图形、符号、色彩、字体、版式和尺度 | 视觉编码表、草图 |
| 07 信息测试 | 检查理解、可读性、准确性、图例与阅读顺序 | 测试记录、修订清单 |
| 08 设计实施 | 完成设计、校对、版权检查和交付 | 最终作品、交付记录 |

## 三层决策必须分开
1. 基础信息逻辑：从编年、层级、编目、字母表、地理五类中判断主导关系。
2. 表现形式标签：从 02 的标签索引中选择一个主标签及可选辅助标签。
3. 视觉风格：摄影、插画、手绘、三维、极简、编辑设计等，按主题和受众选择。

不能因为使用某种风格就推断数据逻辑，也不能因为选择某个表现标签就省略数据结构分析。

## 基础数据硬规则
一行一个最小记录单元，一列一个原子字段，一个单元格一个值。金额、单位、时间、地点、类别代码与文字说明分开存储。经纬度分列并注明坐标参考系。数据来源、采集日期、时间范围、口径、计算步骤和缺失值处理写入数据字典。叙事方案引用基础表中的字段和关联键，不随意破坏原始数据。无法核实的资料标注未知，不将推断冒充事实。

## 设计质量检查
核心问题能否用一句话表达？每个模块是否服务于核心问题？图形是否与数据结构匹配？数量编码是否有单位、刻度或图例？视觉顺序是否符合叙事目的？小字号、颜色对比、阅读路径是否清晰？来源、版权、注释和数据版本是否完整？

## 当前状态
本目录先建立流程规范。具体项目启动后，再按主题创建工作子目录和阶段文件。
