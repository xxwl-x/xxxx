# 05｜叙事框架搭建（由数据列到命题）

## 核心定义
从基础表中选出**某几列**，根据主键关联或计算得到设计视图，再形成一句明确的叙事命题和一个图形模块。**叙事是组合数据字段的下游表达，不应反向污染原始单元格。**

## 组合示例
### 例1：地点名＋GPS→地图地点信息
输入字段：`place.name`＋`place.longitude`＋`place.latitude`；以每个地点一条记录渲染地理点，文字标注绑定名称。地图投影需按坐标系处理。叙事命题示例：“某主题对象在哪些地点出现？”

### 例2：地区名＋GDP数值→地区GDP比较
输入字段：`region.name`＋`gdp.value`＋`gdp.year`＋`gdp.unit`；通过region_id和年份匹配。标题示例：“2025年不同地区GDP如何分布？”（仅作句式示范，非真实数据结论）。柱形图是地区比较，地图则需要明确空间表达目的。

### 例3：日期＋事件→时间轴
输入字段：`event_date`＋`event_title`＋`event_type`，叙事命题：某项目如何逐阶段演变？日期排序不自动产生事件间因果关系。

### 例4：词语＋词频→词云
输入字段：`term`＋`count`或`weight`（计算过程及语料来源另存），词云字号可映射频率；只有文字但无词频时只能作为文字排版，而非声称词频统计。

### 例5：图片ID＋主题名→图片式模块
输入字段：`image_asset_id`＋`topic_name`＋`caption`；照片建立情境，数值编码必须另由明确字段承担。

## 设计步骤
1. 确定读者要回答的核心问题；
2. 按字段和关联键提取数据视图；
3. 检查数据粒度与维度是否可比较；
4. 形成可核验的句式命题（谁/何时/何地/多少/如何变化）；
5. 划分叙事模块，排列阅读顺序并确定模块间转场；
6. 写明每个模块引用的字段/数据集版本与显示单位。
