# 基础数据集质量审查

- [ ] 一行只代表一种定义明确的记录单位
- [ ] 每表有主键；主键不重复
- [ ] 每列只有一种字段含义与类型
- [ ] 每格一个值，不把列表、年月、单位、坐标混入一个字段
- [ ] 经纬度分列并记录坐标参考系
- [ ] 数值单位、货币、比例分母和统计时点可溯源
- [ ] 图片引用只指向一个资产，文件路径与使用许可可查
- [ ] 文字字段是一个完整文本单元；独立事实分字段或记录
- [ ] 多对多关系使用关联表
- [ ] 0、空值、未知、缺测、不适用有不同语义
- [ ] 来源、抽取方式和计算公式已保留
- [ ] 原始、清洗、设计视图已分开
- [ ] 脱敏和版权风险已检查

审查不通过时不得宣称数据集已经可用于定量视觉设计。
