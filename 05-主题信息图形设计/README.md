## 贯穿各阶段的原则

### 1｜数据逻辑、市场标签与视觉风格独立决策
- 数据逻辑：编年、层级、编目、字母表、地理，选择一个主导关系，附加复合关系可以记录；
- 表现标签：[02案例库17种类型](../02-信息图形类型案例/表现形式标签索引.md)，可主辅多标签，如文字型、词云、图片式、比较、流程、地图等；
- 视觉风格：平面、摄影、插画、手绘、三维、编辑设计等；
- 视觉组织：[04-Gestalt](../04-Gestalt-格式塔视觉组织原则/README.md)；
- 图像语言：[06-ISOTYPE](../06-ISOTYPE-基础图形设计方法/README.md)。

### 2｜一格一个原子值
**一行一条最小记录，一列一个原子字段，一个单元格一个值。** 可记录名义数据、量化数据、时间、单一图片资产引用或单段文本。类别多值采用关联表；经纬度分列；数值和单位分列；原始文件与设计视图分离。完整说明见[04数据建模规则](./04-基础数据集构建/原子化数据规则与反例.md)。

### 3｜字段组合到叙事，再到视觉编码
例如：名称＋经度＋纬度→地图上的地点；地区名称＋GDP数值＋单位＋年份→地区GDP比较；词语＋频率→词云；图片ID＋主题名称→摄影主题模块。组合发生在**叙事数据视图**，不在源表中将多个字段合成一个单元格。见[05字段组合方法](./05-叙事框架搭建/README.md)。

### 4｜项目结论必须可追溯
区分真实来源、统计结果、设计推断与待核验内容。保护采访和个人隐私；第三方图像与字体需确认授权，不能把用户上传或参考链接默认视为公开再发布许可。

### 5｜视觉设计必须能解释其信息作用
每个点、线、面、体、图像、符号、色彩或比例都应标明是数据编码、阅读导航还是装饰。视觉美观不能替代统计准确。第07阶段“信息轮盘测试”尚未获得完整定义，保留空白框架，不宣称已经完成。
