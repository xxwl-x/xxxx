# 05｜设计实践经验与原则清单

## 可用于图面审查的工作方法
- 将分组语义明确到字段：同一类别用相同视觉编码，同时避免用靠近、封闭或连线制造错误的关系。
- 使用接近与共同区域组织卡片；保持组内/组间距离有辨识度。
- 同一条关系线需要可追踪的起点与终点；对交叉线、长曲线及时补充标签。
- 图片叠加文字时优先检查图形—背景对比；用蒙版、局部底色增强信息，而不是仅追求美观。
- 镜像比较图必须统一尺度及基线，不能让视觉对称代替数据可比。
- 同一图中若多种分组原则相互冲突，制作两个以上版本做小规模读者任务测试。
