# 06｜Gestalt设计实验与验证

## 单原则A/B实验
1. 明确一个可检验的问题，例如：“增加组间距离是否提高正确分组率？”
2. 仅改变目标线索，尽可能保持内容、图表尺度、标签和阅读任务不变。
3. 记录参与者知识背景与样本人数，随机或交叉展示A/B版。
4. 预先定义指标：正确分组率、完成时间、错误关联次数及主观清晰度。
5. 对干预效果报告结果与局限；样本太少不能推广到总体。

## 设计数据字段
experiment_id、principle、case_id、variant_id、participant_group、task_id、accuracy、time_seconds、error_type、notes。

## 当前状态
只有方法模板，尚无真实受试者数据或结论。所有数值保持待测，不编造改善百分比。
