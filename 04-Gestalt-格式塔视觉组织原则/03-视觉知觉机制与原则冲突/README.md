# 03｜知觉机制与原则冲突

## 同时出现的组织线索
- **接近 vs 相似**：两列颜色一致但行间距更小，读者可能依据行或颜色分组；需要实验判定在特定设计中哪个线索更强。
- **共同区域 vs 接近**：一条边框可能把原本间距较远的项目分组。
- **连接性 vs 距离**：被线连接的远距离节点可能优先被看作整体。
- **图形—背景 vs 相似**：摄影背景复杂时，同色文本也可能不具备清晰的前景分离。
- **良好连续 vs 真实连接**：曲线相交可能被误认为延续到错误目标。

## 分析模板
1. 列出画面中可见的组织线索及其数据意图。
2. 标记不同线索之间是否冲突。
3. 在信息不变时分别改变间距、颜色或边界。
4. 记录受众实际分组及阅读正确率，不仅记录设计师主观判断。
5. 保留反例及失败条件，形成设计经验。

不存在一种永远压倒其他所有因素的固定“Gestalt原则优先级表”；竞争结果受任务、刺激条件和受众经验影响。
