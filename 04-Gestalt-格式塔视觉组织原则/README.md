# 04｜Gestalt 格式塔视觉组织原则

本模块研究视觉元素为何被知觉为群组、连续路径、完整形状和前景/背景。Gestalt是跨类型视觉组织理论，不是第六种基础逻辑，也不是02的第18类表现形式。
