# CASE-0012 数据字典

## 文件
- 文件名：基础数据集.csv
- 当前记录数：0（仅字段模板）
- 数据粒度：一行代表图面中一个可独立识别的局部结构/结构单元。
- 当前状态：图像分辨率不足，无法可靠转录全部结构名称、尺寸和批注，因此不录入猜测记录。

## 字段说明

| 字段 | 类型 | 单位 | 含义 | 状态 |
|---|---|---|---|---|
| record_id | string | — | 记录唯一 ID | 模板 |
| structure_marker | string | — | 图面字母或数字标记 | 待核验 |
| structure_region | string | — | 所属整体区域 | 待核验 |
| structure_description | string | — | 局部结构描述 | 待核验 |
| parent_structure_id | string | — | 上位结构 ID | 待核验 |
| relation_type | string | — | 包含、连接、相邻或重复等关系 | 待核验 |
| annotation_text | string | — | 图面注释逐字转录 | 待高清原图 |
| dimension_value | number | 图面标注单位 | 尺寸数值 | 待高清原图 |
| dimension_unit | string | — | 尺寸单位 | 待高清原图 |
| source_location | string | — | 图面位置/标注定位 | 待核验 |
| confidence | string | — | 识别/转录置信度 | 待核验 |
| verification_status | string | — | 核验状态 | 待核验 |

## 主键与关系
- record_id 为 CSV 主键。
- parent_structure_id 用于表达整体—局部层级；多个结构关系应另建关系表，不在单元格中塞入多个 ID。
- 不把扫描图像像素换算值当作真实尺寸。
- 不把模糊注释补写成确定原文。
