# CASE-0017｜数据字典

## 文件一：道路数据结构模板.csv
当前仅建立字段模板，没有道路级真实观测记录。必须取得原始交通普查数据和道路 GIS 几何后才能填充。

| 字段 | 类型 | 单位/格式 | 含义 |
|---|---|---|---|
| road_id | string | — | 道路路段唯一标识 |
| road_name | string | — | 道路名称 |
| geometry_id | string | — | 对应 GIS 几何记录 |
| avg_daily_vehicles_2011 | numeric | vehicles/day | 2011年日均车辆量 |
| pct_change_previous_year | numeric | % | 相较上一年度的百分比变化 |
| count_method | string | — | 计数方法 |
| observation_period | string | — | 统计时期 |
| source_id | string | — | 原始数据来源 |
| verification_status | string | — | 数据核验状态 |

## 统计口径
- 主地图：2011年日均车辆数；变化率相较上一年度。
- 辅助车辆登记表：2011年登记数量；数量变化和百分比变化相较2000年。
- 两种比较基准不同，不能合并成同一个同比字段。

## 数据建模建议
道路交通主表与道路几何通过 road_id 关联；车辆登记表以 vehicle_type_id 为分类键。GIS 数据需记录坐标参考系、道路网络版本和路段切分口径。不要把地图线宽直接反推成未经验证的流量数值。
