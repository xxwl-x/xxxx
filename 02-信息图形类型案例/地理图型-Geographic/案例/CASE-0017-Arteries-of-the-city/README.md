## 分类理由
真实道路网络和道路空间位置是整张图的组织骨架。道路线宽映射2011年日均车辆量，颜色映射相较上一年度的百分比变化。时间仅是统计时期和变化比较基准，不构成时间轴叙事，因此主归属为地理图型，而非编年型。
