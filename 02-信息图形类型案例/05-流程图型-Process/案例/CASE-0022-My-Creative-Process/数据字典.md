# CASE-0022｜数据字典

## 文件：基础数据集.csv

一行代表一个可辨认的阶段或附属信息单元。S01–S09为阶段/主模块；D01–D10为研究关键词、案例或方向标签，不将它们混作同一层级的流程阶段。

| 字段 | 类型 | 含义 |
|---|---|---|
| stage_id | string | 阶段或信息单元唯一编号 |
| stage_name | string | 图面可辨认标题/标签 |
| sequence_order | integer | 主流程阅读顺序；非日期 |
| stage_role | string | 起点、触发、研究、构思、方案、总结等分析角色 |
| description | string | 可辨读说明；不清晰时标待核验 |
| evidence_status | string | 图面证据状态 |

## 文件：关系边.csv

一行代表一条阶段间连接。from_id、to_id关联基础数据集中的stage_id。当前边顺序依据连续路径与整体版面阅读推定；箭头端点细节待高清原图复核。

## 口径约束

- 不从图面推测具体日期、阶段耗时、效率或项目绩效。
- 研究关键词与案例标签不自动视为独立流程阶段。
- 图标仅作情境说明，不把图标数量作为统计数据。
- 文字太小无法辨读时，保留“待高清核验”，不补写猜测内容。
