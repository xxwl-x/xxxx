## 分类理由

橙色道路是全图的主导连接结构，从画面下部向上蜿蜒穿过多个场景，并通过年份标牌和人物/建筑场景构成经历节点。教育、专业能力、奖项和目标等个人信息依附在这条旅程上。它不是单纯的栏目式简历排版：道路将信息模块组织成一条有方向、有阶段感的经历路线，因此按用户指定归入流程图型。

## 归档边界

栏目标题和道路/场景结构可辨认；部分说明文字和年份标牌较模糊。当前不转录无法确认的姓名、学校、奖项名称、精确年份或技能数值。技能柱状图没有清晰可读的数值轴，不能据柱高推断绝对熟练度。
