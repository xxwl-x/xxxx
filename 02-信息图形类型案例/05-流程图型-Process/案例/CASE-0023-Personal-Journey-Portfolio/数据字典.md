# CASE-0023｜数据字典

## 文件：基础数据集.csv

一行代表一个个人经历里程碑或一个个人资料栏目。record_type区分milestone与profile_section。

| 字段 | 类型 | 含义 |
|---|---|---|
| record_id | string | 记录唯一编号 |
| record_type | string | milestone或profile_section |
| label | string | 图面可辨认的栏目/经历标签 |
| year_label | string | 年份标牌文字；无法核实时留空 |
| route_order | integer | 沿道路的分析性阅读顺序，不等于已核实的事件日期 |
| description | string | 可见内容摘要；模糊处标待核验 |
| evidence_status | string | 图面证据状态 |

## 文件：关系边.csv

一行代表道路主路径中两个里程碑之间的连接。边顺序基于橙色道路的连续走向分析；需要高清图进一步确认每个年份牌与具体事件的对应关系。

## 数据纪律

- 不猜测个人姓名、学校、联系方式、奖项名称或履历正文。
- 年份标牌模糊时不填猜测数字；不得将推测年份当作事实。
- 技能柱形没有明确量表、单位和刻度，不能将柱高转换成分数、百分比或真实熟练度。
- 等轴测插画用于空间叙事，不提供现实地理坐标或建筑尺寸。
- 资料栏目与道路里程碑分开建模，避免将栏目本身误作时间事件。
