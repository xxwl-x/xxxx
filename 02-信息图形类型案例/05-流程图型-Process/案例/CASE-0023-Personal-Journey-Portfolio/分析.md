# CASE-0023｜Personal Journey Portfolio：A—E 五维分析

## 0. 类型判断与证据边界

**主表现标签：05｜流程图型。** 画面以一条醒目的橙色道路作为主线，路线从画面下方进入，向上蜿蜒经过多个场景和年份标牌。读者沿道路阅读个人经历，路径承担了组织信息、暗示先后和连接不同栏目/里程碑的作用。

**五大基础逻辑主归属：编年型。** 道路上的年份标牌与教育、奖项、经历和目标共同形成个人发展时间线。图面年份因分辨率较低无法可靠完整转录；因此只能确认它使用时间/里程碑组织方式，不能确认每个具体年份和事件的精确对应。

**可辨认栏目：** About Me、Contact、Education、Specialties、Awards、Target。画面还有建筑、人物、交通工具、树木、路牌和道路场景。Specialties 区域呈现多个技能缩写及竖向柱形。

**证据边界：**
- 总标题、作者姓名和具体身份信息未能从图面确认；
- About Me、Contact、Education、Awards、Target 的正文小字无法可靠逐字转录；
- 年份路牌存在，但具体数字和节点对应需高清原图复核；
- Specialties 柱形图缺少清晰数值轴、单位和图例，不能解释为可量化的专业能力分数；
- 等轴测场景的空间位置是叙事构图，不是现实地理地图。

## A｜基本数据逻辑

### 1. 最小记录单元

本图包含两类相互关联的信息单元：

**经历/里程碑记录（Milestone）：**
- milestone_id：里程碑编号；
- year_label：年份标牌文字（未核实则留空）；
- milestone_type：教育、经历、奖项、目标等；
- description：对应说明；
- route_order：沿道路的阅读次序；
- evidence_status：图面可读、部分可读或待核验。

**个人资料栏目（Profile section）：**
- section_id：栏目编号；
- section_name：About Me、Contact、Education、Specialties、Awards、Target；
- section_content：栏目文字；
- related_milestone_id：若能确认与道路节点关联则填写。

技能图表另作为一类辅助数据：skill_label、bar_height_visual、scale_status。没有可见刻度时，bar_height_visual 仅是图形观察，不是实际能力分数。

### 2. 数据结构本质

底层是**个人经历的有序里程碑序列＋个人资料栏目＋技能属性展示**：
- 道路与年份牌：建立先后/经历路径；
- 栏目：补充个人身份、联系方式、教育、奖项和目标；
- 技能条形图：对若干专业工具/能力做视觉对照。

道路路线是叙事主线，栏目是附着其上的信息模块。不能把栏目排列顺序直接当作所有人生事件的精确时间顺序。

## B｜统计图形与计算方式

本图不是以统计分析为核心的图表信息图。主要图形方法包括：

1. **路径式流程图：** 橙色道路连接场景和经历节点；
2. **时间里程碑标记：** 路牌/年份牌提示人生阶段；
3. **等轴测场景插画：** 建筑、人物、交通工具和环境物件将抽象经历转为旅程场景；
4. **小型条形图：** Specialties 区域以多根竖条比较若干技能标签的视觉高低。

### 技能条形图的统计限制

图中柱形没有清晰可见的数值刻度、单位、基准或数据来源。可确认它使用柱高作相对视觉区分，但无法判断柱高究竟表示熟练程度、掌握程度、兴趣权重还是作者自评。因此：
- 不计算具体分数；
- 不将柱高转录为百分比；
- 不推断技能排名以外的真实能力差异；
- 若后续取得原始数据，应补充指标定义、量表范围和评分方法。

## C｜视觉编码

| 视觉通道 | 图面作用 | 判断与风险 |
|---|---|---|
| 线／道路 | 橙色连续路线连接经历节点 | 核心流程语法；道路方向引导阅读 |
| 点／路牌/标记 | 标记年份或重要里程碑 | 作为阶段锚点，不代表数量大小 |
| 面／场景平台 | 建筑地块、道路转弯和场景底面 | 形成等轴测空间叙事，不是地理分区数据 |
| 体／等轴测建筑与人物 | 教育、工作、生活和经历场景 | 把履历内容场景化；不应解读为真实比例模型 |
| 符号 | 树木、车辆、路灯、路牌、人物等 | 作为环境和经历语义提示 |
| 色彩 | 橙色道路、浅绿色背景、灰米色建筑、深色文字 | 橙色突出主路线；背景与建筑色形成柔和层次 |
| 文字 | About Me、Education、Specialties、Awards、Target 等栏目及说明 | 栏目名帮助定位信息；年份牌为时间提示 |
| 柱形高度 | Specialties 区域的技能对比 | 缺少尺度与单位，不能当作精确数值 |

### 编码优化建议

- 在道路节点处统一年份牌样式，使年份与经历模块建立清楚的一对一对应；
- 以小箭头或方向提示减少道路回转造成的阅读歧义；
- 让每个栏目标题与对应场景/里程碑之间有明确的连接关系；
- 技能柱形图补充刻度、量表定义和数据来源；若无法提供，应改为非定量的技能标签；
- 保持等轴测插画为叙事辅助，避免插画细节压过履历文字。

## D｜数据／信息架构

### 建议的基础数据表

**Milestones：一行一个道路里程碑。**
字段：milestone_id、year_label、milestone_type、description、route_order、evidence_status。

**Profile_sections：一行一个个人资料栏目。**
字段：section_id、section_name、section_content、related_milestone_id、evidence_status。

**Skills：一行一项专业技能。**
字段：skill_id、skill_label、visual_bar_order、visual_bar_height、metric_definition、scale_min、scale_max、evidence_status。若没有原始量表，metric_definition、scale_min、scale_max 留空。

**Route_edges：一行一段道路连接。**
字段：edge_id、from_milestone_id、to_milestone_id、route_order、direction_evidence、evidence_status。

### Excel 工作簿建议

- Sheet 1 Milestones：经历与年份里程碑；
- Sheet 2 Profile sections：个人资料栏目；
- Sheet 3 Skills：专业技能标签和量表定义；
- Sheet 4 Route edges：道路节点连接关系；
- Sheet 5 Visual encoding：道路、路牌、等轴测场景与栏目编码说明。

当前不把模糊正文或年份牌猜填进数据表；技能柱高仅保留“无量表的视觉柱形”这一观察，不转换为数值评分。

## E｜视觉叙事架构

1. 读者首先看到贯穿版面的橙色道路，理解“个人经历是一段旅程”的隐喻；
2. 从道路下方的起始区域进入，沿道路经过早期里程碑与人物/交通场景；
3. 道路中段连接教育相关建筑与 Education 栏目，形成学习经历的信息段；
4. 继续沿路线浏览 Specialties，看到专业技能的柱形对照；
5. 再沿道路经过 Awards 区域及相关场景，阅读个人成果；
6. 道路向上延伸至 Target，形成未来方向或职业目标的收束；
7. About Me 与 Contact 等栏目补充个人介绍和联系信息，作为贯穿履历主线的辅助信息。

整体叙事是“个人起点—教育与成长—专业能力—成果/奖项—未来目标”。橙色道路把原本分散的履历栏目变成一段连续的视觉旅程；等轴测插画增强空间感和记忆点。

## 可复用设计方法

- 用连续道路/路径隐喻组织个人经历、学习和职业目标；
- 以年份路牌或里程碑节点建立时间节奏；
- 将个人资料栏目与主路径关联，而不是让栏目成为互不相干的文字块；
- 用等轴测场景将抽象履历转成可视化情境，但须保证关键文字可读；
- 对技能柱形等定量图形必须给出尺度和含义；没有量表时不要暗示精确评分。

## 分类核验结论

- 主表现标签：05｜流程图型；
- 五大基础逻辑：编年型（个人经历/里程碑的先后组织，具体年份待核验）；
- 辅助表现：13｜视觉简历；16｜三维型；06｜比较型（技能柱形图的辅助表现）；
- 主叙事结构是道路连接的个人经历旅程，不是地理地图；
- 年份、正文、个人身份、奖项细节及技能量表均待高清原图或原始资料核验。
