# CASE-0021｜数据字典

## 文件1：节点数据.csv
一行代表一个图面节点。

| 字段 | 类型 | 含义 |
|---|---|---|
| node_id | string | 节点唯一编号 |
| label | string | 图面节点标签 |
| node_group | string | 策略/规划/品牌资产/传统媒介/数字媒介等分析分组 |
| icon_type | string | 节点图标类别 |
| visual_position | string | 图面位置描述；不作为数据变量 |
| evidence_status | string | 图面可读/待核验 |

## 文件2：关系边数据.csv
一行代表一条节点关系。

| 字段 | 类型 | 含义 |
|---|---|---|
| edge_id | string | 关系边编号 |
| source_node_id | string | 起点节点 |
| target_node_id | string | 终点节点 |
| relation_type | string | Direct Pathway / Indirect Pathway / Interesting Facts |
| line_style | string | 实线/浅色虚线/橙色虚线 |
| direction | string | 图面箭头方向 |
| evidence_status | string | 图面可读/待高清核验 |

## 文件3：事实注释.csv
一行代表一个统计事实或文字注释。

| 字段 | 类型 | 含义 |
|---|---|---|
| fact_id | string | 注释编号 |
| fact_text | string | 注释原文或转述 |
| metric_value | number/string | 数值；未核实则留空 |
| unit | string | 百分比、小时等 |
| related_node_id | string | 关联节点，可为空 |
| source_text | string | 图面标注的来源 |
| verification_status | string | 待核验/已核验 |

## 数据纪律
- 节点与关系边必须分表；不要将一条边复制成两个节点。
- “Interesting Facts”与直接/间接路径不同，若图例语义是事实提示，应保留为独立类型或放入事实注释表。
- 当前图像中文字较小，关系边CSV和事实CSV保持空模板，不猜测端点或百分比。
- 节点大小和位置没有数值图例，不得转成预算、重要性或绩效指标。
