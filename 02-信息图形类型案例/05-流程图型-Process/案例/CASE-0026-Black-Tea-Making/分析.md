# CASE-0026｜BLACK TEA（A—E 五维分析）

## 0. 类型判断

**主表现形式：05 流程图型。** 画面用连续路径、编号节点和动作插画解释红茶制作/冲泡的先后步骤。

**辅助表现：04 示意图型。** 茶壶、茶杯、茶叶、温度、茶具等插画用于解释材料和操作方式。**07 地标型仅为辅助模块**：右上“World Black Tea”中的世界地图提供红茶产区的地理背景，未主导全图结构。

**五大基础逻辑主归属：编年型。** 核心冲泡流程的最小关系是步骤先后。注意：图中历史、品牌、茶具和调饮种类属于补充目录，不能全部强行纳入时间顺序。

## A｜基本数据逻辑

### 1. 最小记录单元
主流程最小单元为“流程步骤”：
- step_id：步骤编号；
- process_name：所属流程（红茶制作/冲泡）；
- step_name：步骤名称；
- order_index：先后顺序；
- action：操作动作；
- material_or_tool：材料或器具；
- condition：温度、时间、用量等条件；
- note：图面说明。

地图辅助模块最小单元为“产区/国家或地区”，但截图中的标注较小，不能据此补录具体地点清单。

### 2. 数据结构本质
主体是有向步骤序列：Step 1 → Step 2 → Step 3 → Step 4。制作流程和冲泡流程应拆成不同 process_id，不能把“茶叶生产”与“泡一杯茶”的步骤混为同一条流程。

辅助信息应独立建表：
- TeaFacts：红茶概念与历史条目；
- Regions：产区地理实体；
- Brands：品牌条目；
- Teaware：茶具目录；
- TeaVariants：直饮、调饮、冰茶等类别。

### 3. 数据边界
截图可辨认部分步骤标题，但正文小字不足以可靠转录。具体温度、时间、茶叶克数和产地名称须标记待核验，不能从视觉示意推断为精确配方。

## B｜统计图形与计算方式

本图不以统计图表为核心，主要使用流程图与说明性图示：
1. 连续路径＋编号节点：表达操作顺序；
2. 茶叶制作步骤图标：表达工序类别；
3. 温度/时间文字标注：提供操作条件（具体数值须高清核验）；
4. 世界地图：作为地理背景与产区索引，不承担可量化的空间统计；
5. 茶具图标矩阵：以图像目录方式展示器具；
6. 调饮分支：以类别标签和小型器具/配料插画展示不同茶饮形式。

无须从画面计算统计量。若后续制作可执行配方表，需以可靠来源补足温度、浸泡时间、茶水比等参数，并记录单位。

## C｜视觉编码

| 视觉通道 | 图面作用 | 观察 |
|---|---|---|
| 连续线/路径 | 连接冲泡步骤 | 金黄色路径承担主要阅读导航 |
| 编号圆点 | 标示步骤先后 | 01—04等节点强化操作顺序 |
| 插画/符号 | 茶壶、茶杯、茶叶、茶具 | 将抽象步骤转为可识别动作和物件 |
| 色彩 | 深蓝底、金色路径、红色步骤标题、粉色壶具 | 深蓝建立底色，金色强调主路径 |
| 位置 | 左侧制作流程、中部冲泡主流程、右侧知识模块、底部器具目录 | 形成主流程与知识补充的版面分区 |
| 地图 | 右上世界红茶产区 | 只作为辅助地理信息，不是主地图叙事 |

**设计优点：** 用连续路径把主要操作串起来，同时把茶史、产区、品牌、器具等知识放在外围，形成“主操作流程＋主题百科”的复合版面。

**优化建议：** 主路径与次级注释应有更明显的层级差；流程节点文字可提高字号；地图应增加清晰图例和产区标记说明；步骤条件应明确单位。

## D｜数据／信息架构

建议拆为以下表：

**Processes：** process_id、process_name、process_scope（制作/冲泡）。

**Steps：** step_id、process_id、order_index、step_name、action、material_or_tool、condition、unit、source_note。

**TeaFacts：** fact_id、topic、description、period_or_scope、source_note。

**Regions：** region_id、country_or_region、geographic_role、map_label、source_note。

**Brands：** brand_id、brand_name、country_or_region、source_note。

**Teaware：** item_id、item_name、function、illustration_label。

**TeaVariants：** variant_id、variant_name、ingredients、preparation_method。

每张表一行对应一个明确实体/步骤，流程关系另用关系边表，不把说明性文字和流程连接关系混在一起。

## E｜视觉叙事架构

1. 顶部大标题“BLACK TEA”确立主题；
2. 左侧从采摘、萎凋、揉捻等环节解释红茶制作背景；
3. 中部以茶叶、茶壶、茶杯和金色路径作为主视觉，按编号引导冲泡步骤；
4. 右侧补充红茶定义、历史、世界产区与品牌；
5. 底部展示茶具目录，以及调饮茶、冰茶等延展形式；
6. 最终落到右下角一杯成品红茶，形成从原料/工序到饮用结果的视觉闭环。

叙事逻辑是“认识红茶→了解制作→学习冲泡→认识产区与品牌→了解器具和变化形式→饮用成品”。

## 可复用方法与边界

- 用一条视觉主路径串联主要操作步骤；
- 把百科性信息放在外围，避免打断主流程；
- 地图作为辅助模块时必须明确其地理信息用途；
- 图标适合解释动作和器具，不应被误认为统计单位；
- 温度、时间、用量必须有来源和单位，不能凭插画估算；
- 对复杂主题可采用“流程主轴＋知识侧栏＋工具目录”的复合架构。

## 归档结论

主表现标签为05流程图型；辅助为04示意图型和07地标型（小地图模块）。五大基础逻辑主归属为编年型（操作顺序）。图面小字、具体参数和产区清单待高清原图/原始资料核验。
