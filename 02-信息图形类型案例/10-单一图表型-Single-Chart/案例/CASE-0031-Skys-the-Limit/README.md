# CASE-0031｜Sky’s the limit

- **主表现：10 单一图表型（以底部建筑高度比例轮廓对照为主视觉）**
- **辅助表现：01 混合型、06 比较型、07 地标/地图型**
- **基础组织逻辑：编目型**（一栋楼一条记录，按城市、建设状态和高度分类与比较；辅助地理编码）
- 图面主题：中国高层建筑分布、全球最高建筑高度对照，以及Sky City预测项目
- 该图并非只有一个统计模块；顶部包含中国地图上的高度线、方格数目比较及Sky City相关指标。单一图表归档基于占据画面下半部的建筑实物轮廓高度对照这一主视觉，其他模块如实登记。
- 图中有“如果建成”的条件语气，不将Sky City计划视为已完成事实。
- 图面数字来自历史作品，并非2026年全球建筑高度榜单。
- 原图为用户本次对话上传，公开再发布许可尚未核实，原图二进制未复制到公开仓库。
