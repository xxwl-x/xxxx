# CASE-0031｜Sky’s the limit：A—E案例分析

## 0 分类判断
**主表现：10 单一图表型；辅助：01 混合型、06 比较型、07 地标型。** 主视觉是画面下半部按共同基线摆放的著名摩天楼彩色剪影，楼高直接对应垂直比例尺寸。其上还有中国地图分布的城市与建筑高度线、右上方的世界百强数量方格图及Sky City项目事实框，因此不能简单断言全图严格只有一个图表。

**基础数据逻辑：编目型。** 主要数据对象是建筑：每栋具有名称、地点、真实或计划高度、建成/在建/拟建状态、年份等属性。中国地图提供地理关系，图底高度对照提供比较关系，但页面主要是在共同指标框架中整理建筑条目。

## A 基本数据逻辑
核心最小单元是**建筑实体（building）**。推荐字段：
- building_id、name、city、country、height_m、completion_year、development_status、source、verification_status
- planned_height_m 与 measured_height_m 分开，避免把规划高度当作已建成高度。
- 所有高度应注明是建筑高度/建筑顶部/天线尖顶等哪种计量口径；原图未必足够辨认。
另外的“世界前100高楼”采用 country_count 计数，属于国家数量对照而非建筑单体数据；Sky City信息卡另建 project_fact 条目。

## B 统计图形与计算
1. **主图：同基线实物轮廓比较图（to-scale pictorial silhouette comparison）**。将不同建筑外形按高度缩放后以共同地面基线排列，轮廓高度相当于条形图的数值长度，但建筑外形保留辨识性。图面“World's tallest”提供部分具体名称与米数。
2. **地图高度线：** 中国地区背景地图上以垂直线和高度数字展示不同城市的高楼；色彩区分Completed、Construction、Proposed（具体色彩映射需图例核对）。
3. **右上单位方格图：** 标题“Top 100 skyscrapers in the world by 2020”，其中 China 56 buildings 与 Rest of the world 44 buildings；可以计算56/100=56%，44/100=44%，但这是图面的预测/历史设定，不是2026年事实。
4. **右侧项目事实模块：** Sky City 的若干高度、楼层、速度/人口等事实说明；小字不全部转录。

方法与风险：同一垂直尺度必须保证建筑高度比例；不同建筑冠部或地下基座要统一高度定义。地图顶部线柱与底部建筑剪影是否使用同一个物理缩放比例尚未证实，因此不跨模块直接量尺。

## C 视觉编码
| 通道 | 作用 |
|---|---|
| 建筑剪影高度 | 量化建筑高度 |
| 建筑外形 | 保留建筑识别信息，不等于额外数据轴 |
| 色彩 | 区分楼体并增强识别；地图上的状态类别需以图例为准 |
| 地图位置 | 标示中国城市空间分布；不是主图高度轴 |
| 细直线/顶部数字 | 地图上的楼高提示，辅助精确读数 |
| 方格单元 | 右上100单位图，表达两组数量分配 |
| 文本/箭头 | 标注名称、年份、城市、拟建项目的条件信息 |
| 淡灰地图与留白 | 降低底图干扰，突出定量线条和建筑 |

视觉优势：数据单位（建筑）被直接做成量化符号，比普通柱形更易建立建筑身份联想。风险：大楼宽度、颜色、遮挡和重叠会暗示未定义的体积/排名；建筑轮廓不应按面积或质量解读。

## D 信息架构
建议：
- Buildings表：building_id、name、city、country、height_m、year、status、height_definition、source。
- SkylineComparisons表：comparison_id、building_id、baseline_id、scale_factor、chart_order。
- WorldTop100Counts表：group、count、target_year、is_projection。
- SkyCityFacts表：fact_id、metric、label_value、unit、conditional_status。
- Geography表：place_id、country、city、coordinate_reference。
主图单楼一行；未读清的精确高度不猜录，CSV仅保存清楚识别的对象与“待核验”标记。

## E 视觉叙事架构
1. “Sky’s the limit”以超级高楼主题引入，前言突出中国即将出现的极高建筑项目。
2. 中国地图及城市高度线提出“在何处、规划/建造多高”的地域分布。
3. 右上100格图将中国与世界其他地区作数量对照。
4. 右侧Sky City事实框展开单个项目的宏大设想，但图面带条件语气。
5. 底部完整比例剪影让读者直接“看见”不同建筑高度的尺度差，形成最强视觉记忆点。

## 可复用方法
- 当比较对象有稳定可辨形态时，用等比例实物轮廓替代抽象柱形，但必须建立共同基线与同一测量标准；
- 把状态类别（建成/在建/规划）独立编码，不能与高度混作一个变量；
- 将宏观空间分布与对象尺度比较分层，标清各自图例；
- 对计划/未来预测使用明确的条件性语句及目标年份；
- 若同一页面存在多张统计图，记录其为单主图＋辅助图的组合，而非“纯单一图表”。
