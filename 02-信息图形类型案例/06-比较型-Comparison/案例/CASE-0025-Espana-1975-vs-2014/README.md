## 分类理由

画面以1975和2014两个年份作为左右对照的时间截面，比较同一国家在住房、就业、人口、收入、消费和人口年龄结构等方面的变化。中央镜像式半圆图展示收入相关指标，底部镜像人口金字塔/条形矩阵展示不同年龄段与社会指标。它的核心是跨时期社会指标对照，而不是单纯的时间轴。
