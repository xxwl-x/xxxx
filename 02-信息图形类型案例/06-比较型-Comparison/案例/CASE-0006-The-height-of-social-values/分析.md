# CASE-0006｜The height of social values

## 基本信息
- 原标题：The height of social values
- 发布媒体：South China Morning Post（图面署名）
- 图面日期：2014-12-23
- 主体：不同功能建筑的高度比较及建筑形态与社会价值的关联
- 主要视觉：按统一高度尺度排列的建筑立面天际线
- 主表现标签：06 比较型 Comparison
- 辅助表现标签：01 混合型 Mixed Charts（图形、清单、文字、分类图例组合）
- 五大基础逻辑主归属：层级型（以连续高度值形成可排序的量级与排名层次；此处并非父子包含层级）
- 辅助基础逻辑：编目型（各建筑按功能类别标注）
- 数据证据：依据用户提供的 2014-12-23 作品图片；原图二进制尚未复制到此仓库
- 观察与事实边界：图面可确认高度比较和颜色类别；个别建筑名、数值和精确年代需要高清原件逐一核验

## A. 基本数据逻辑
最小记录单元是一栋建筑。每条记录具有建筑名、所在城市/国家、落成年份、高度（米）、建筑功能类别、图形与来源。作品核心逻辑是对象高度的定量比较与次序/层级，类别属性进一步解释不同功能的高度差异。顶部为建筑名录数据表，底部为相同比例的形态对照。

主导关系是 **高度（定量）→ 排列/排名 → 视觉量级差异**；并非建筑之间的上下级隶属。若未来严格将“层级型”限定为树/统属关系，则需要将本案主归属改为编目型（按建筑对象及类别组织），不可不说明定义边界而强行归类。

## B. 使用的统计图形与计算方式
- 按建筑物实际高度构建的 **比例立面比较图 / pictorial bar comparison**，以建筑形态取代抽象柱形。
- 使用同一垂直高度参照尺（右侧米刻度）比较高低。
- 上方建筑资料清单呈现建筑名、所在地区、年份及高度等信息；读者可对照数据和可视形态。
- 不同功能建筑以分类颜色/图例编码，辅助观察类别分布。
- 可复建的数据计算：统一单位换算（米）、按照高度排序、以共同线性高度比例映射 y 尺寸；分类型计数或最高值统计只能在完整数据表取得后计算。
- **不能仅凭截图推断图中所有高度值、排名或比例细节的准确性**；横向排列的具体排序规则应在高清原件核实。

## C. 视觉编码
- 点：每栋建筑在水平空间具有独立位置，底部刻度辅助对象定位。
- 线：统一底线、垂直米刻度以及建筑细部线描提供可比性和身份识别。
- 面：建筑外轮廓与建筑材质立面图像传达具体形态，色彩区分用途。
- 体：透视/立面细节增强真实感；高度应以统一数值尺度编码，避免透视效果篡改量级。
- 符号：每栋建筑插画即专属象形标识，不是重复固定单位的 ISOTYPE 量化图符。
- 色彩：图例使用不同色调区分政府/公共、宗教、住宅、办公、综合、酒店、纪念性建筑等功能类别；颜色准确对应关系依高清图例复核。
- 文字：居中大标题提供论点；顶部小字号表格提供数据证据与来源。
- 视觉层次：顶部细密清单与下方大型建筑天际线构成“精确表格+直观比例”的双重读法。

## D. 数据与信息架构
建议的重建表结构：building_id、building_name、city、country、completion_year、height_m、function_category、image_ref、source。**一行=一栋建筑**；精确完成年份、建筑高度定义（建筑高度/结构高度/尖顶等）必须以原始数据口径为准。

页面信息层次为：顶部详细表格 → 论点式标题及短说明 → 功能颜色图例 → 高度比例建筑群 → 统一刻度与来源。

## E. 视觉叙事架构
提问“建筑的高度体现了怎样的社会价值？”→ 用功能图例建立比较对象 → 让建筑从真实轮廓中呈现量级差异 → 超高建筑形成视觉高潮 → 引导读者思考不同社会时期及建筑功能的优先关系。该叙事是作品的编辑性解释，**不能只凭高度证明社会价值变化存在严格因果关系**。

## 设计方法与知识回写
1. 真实对象的比例立面可以同时承载身份识别和定量比较。
2. 精确数值列表与比例插画分工：表格满足查证，插画强化观察。
3. 保持同一测量基线及尺度，避免视觉修辞使对象失去可比性。
4. 功能分类采用稳定色彩，不将面积、建筑宽度或立面复杂度误读为数量。
5. 本案例支持“比较型”中使用具体实物替换抽象柱形的设计方法；对“层级型”的量级排序边界应持续检验。
