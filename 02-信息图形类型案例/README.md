# 02-信息图形类型案例

本目录只按用户指定的三类案例组织，不按“编年型、层级型、编目型、字母表型、地理图形”建立案例分类。

## 案例分类

1. [混合型信息图形（Mixed Charts）](./01-混合型信息图形/)
   - 保存 1 个说明文档；说明文档依据用户提供的案例图持续分析、归纳和更新。
2. [文字型/列表型信息图形（Informational / List Infographics）](./02-文字型与列表型信息图形/)
   - 收录用户提供的对应案例图及逐例分析。
3. [时间轴型信息图形（Timeline Infographics）](./03-时间轴型信息图形/)
   - 收录用户提供的对应案例图及逐例分析。

## 案例分析与更新原则

- 所有说明、原则、方法均以用户提供的案例图为分析依据。
- 未收到案例图前，不预先编造案例分析结论。
- 每新增案例，先记录该案例的视觉与信息证据，再更新相应说明文档中的共性、差异、原则和方法。
- 原始案例图片保存在本目录对应类别中。
- `01-信息图形数据逻辑` 中的五份定义文档不保存案例图片，只通过 Markdown 文本链接指向本目录相关案例。
