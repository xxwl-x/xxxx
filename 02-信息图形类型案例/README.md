# 02｜信息图形类型案例

本目录严格参照 [fengbaifan/Infographic-Style-Repository](https://github.com/fengbaifan/Infographic-Style-Repository/tree/main/02-%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2%E7%B1%BB%E5%9E%8B%E6%A1%88%E4%BE%8B) 的目录编号、名称和层级建立。

## 分类边界

- **五种基础组织逻辑**是作品的类型学主归属：编年型、层级型、编目型、字母表型、地理图型。每件作品必须依据主导信息关系选择一个主归属。
- **01–17** 是市场化表现形式标签，可作为案例检索与制作方法索引；不等同于五种基础组织逻辑。
- **18｜ISOTYPE** 是跨类型基础图形设计方法专项标签，不是第 18 种市场表现形式，也不是第六种基础组织逻辑。
- 同一案例只保留一份正式 CASE 档案；如需多个标签，通过索引链接，不重复存图。
