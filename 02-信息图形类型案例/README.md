# 02｜信息图形案例与表现形式

本目录负责存放作品案例和表现形式标签。表现形式不等于基础数据逻辑：每件作品先从五种基础逻辑中选择一个主归属，再选择一个主表现标签，可增加辅助标签。

## 已建立的案例分类目录
1. [混合型信息图形](./01-混合型信息图形/)：多种统计图形、符号和信息模块在统一主题下协同。
2. [文字型与列表型信息图形](./02-文字型与列表型信息图形/)：以说明、条目、知识点或清单为主要内容组织方式。
3. [时间轴型信息图形](./03-时间轴型信息图形/)：以时间或阶段序列作为主要视觉呈现方式。

## 表现形式标签体系
本库另设多选标签索引，包括示意图型、流程图型、比较型、地标/位置型、图片式、层级表现型、单一图表型、文字可视化、解剖型、视觉简历、手绘型、编年与编目复合表现、三维型、词云等。完整说明见[表现形式标签索引](./表现形式标签索引.md)。

标签索引先于目录扩张：只有在收到并分析相应案例后，才为高频标签建立专门目录，避免空目录堆积。

## 案例入库原则
原图、来源与版权状态可追溯；分开记录图面事实、数据转录、计算结果和推断；细节不可辨认时标记待核验；每案尽可能配套基础数据 CSV 与数据字典；同一作品只保留一份正式案例档案。
