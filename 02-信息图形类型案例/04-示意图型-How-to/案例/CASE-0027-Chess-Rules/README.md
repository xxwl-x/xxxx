## 分类理由

整张图以棋子、棋盘格和箭头示意移动规则、吃子、王车易位、吃过路兵和开局等操作。棋盘是规则演示的抽象空间，不是真实地理位置或地理分布图。因此主归档为示意图型，而非地图型。
