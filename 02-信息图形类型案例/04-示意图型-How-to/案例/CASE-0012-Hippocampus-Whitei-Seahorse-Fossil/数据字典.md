# CASE-0012 数据字典

## 文件
- 文件名：基础数据集.csv
- 当前记录数：0（仅字段模板）
- 数据粒度：一行代表图面中一个可独立识别并经核验的构件/构件组。
- 当前状态：低分辨率图像无法可靠辨认 A–E 具体零件名称、完整尾部编号、尺寸数值和手写注释；因此不录入猜测记录。

## 字段说明

| 字段 | 类型 | 单位 | 含义 | 状态 |
|---|---|---|---|---|
| record_id | string | — | 构件记录唯一 ID | 模板 |
| component_marker | string | — | 图面字母/数字标记，如 A–E | 待核验 |
| component_region | string | — | 构件所在视觉区域 | 待核验 |
| component_description | string | — | 经核验的构件描述 | 待核验 |
| relation_type | string | — | 与其他构件的连接/重复/包含关系 | 待核验 |
| dimension_value | number | 图面标注单位 | 尺寸数值 | 待高清原图 |
| dimension_unit | string | — | 尺寸单位 | 待高清原图 |
| annotation_text | string | — | 手写批注的逐字转录 | 待高清原图 |
| source_location | string | — | 图面位置或标注定位 | 待核验 |
| confidence | string | — | 转录置信度 | 待核验 |
| verification_status | string | — | 核验状态 | 待核验 |

## 主键与关系
- record_id 为本 CSV 主键。
- 如后续需要表达一件作品中一个部件连接多个部件，应新增独立的构件关系表，不在单元格中塞入多个 ID。
- 不把图像像素测量值当作实际工程尺寸。
- 不把无法辨认的手写内容补写成作者原文。
