## 作品背景核验

公开资料将 *Hippocampus Whitei* 记为 Christopher Trotter 的海马“化石”雕塑，并说明其由机械零件构成、约 3 米高；艺术作品路线资料将其列在 Tannum Sands 的 Millennium Esplanade。此背景用于辨别图面属性，不代表已核实这张 1987 年设计图与后来公开展示作品的全部版本关系。
