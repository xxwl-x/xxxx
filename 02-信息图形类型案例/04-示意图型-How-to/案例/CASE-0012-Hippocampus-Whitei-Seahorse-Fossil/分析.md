## 2. 分类结论与关键校正

本图**不应仅凭“海马化石”标题和类似脊椎的外形归入解剖型**。

公开作品资料将 *Hippocampus Whitei* 描述为 Christopher Trotter 创作的海马“化石”雕塑，由机械零件构成，约 3 米高；另一份艺术作品路线资料将该作品列在 Queensland 的 Tannum Sands、Millennium Esplanade。该背景改变了图像的解释：画面不是在科学地说明海马真实骨骼，而是在展示一件机械拼装雕塑的设计/构造方案。

因此：
- 主表现形式是**示意图型/技术标注图**：通过构件轮廓、尺寸线、编号、字母标记和引线说明设计对象及局部构造。
- 辅助表现形式是**手稿型**：画面以手绘线稿、阴影和手写批注构成。
- 五大基础组织逻辑主归属建议为**层级型**：从整体海马形态进入头部、躯干、尾部等构成区，再定位到机械构件、连接件和局部组件，表达整体—部分及部件装配关系。

### 为什么不是解剖型
解剖型应以真实生物/人体/对象的器官或结构关系为主要解释对象。本图的“骨骼”外观是艺术造型语言；外部资料说明雕塑由机械零件构成。图面标注重点是设计构件、尺寸、构造和制作意图，而非海马的真实解剖、生理功能或科学测量。因此不把它归入 12 解剖型。

### 为什么不是编年型、编目型或地理图型
- 没有以事件先后或时间阶段组织内容，尺寸数字不构成时间序列。
- 字母 A–E 和尾部数字是图面定位/构件索引，不是按类别列举对象的编目逻辑。
- 没有地图、地点分布或空间数据层；“Calliope Shire Council”是委托署名，不代表地理图型。

## B｜统计图形、计算方式与工程图形语言

本图主要使用的是工程/设计表达方式，而非统计图形：
- **主视/整体构造示意**：在一张平面图上表达雕塑整体外形及构件关系。
- **局部标注图**：A–E 圆圈字母和尾部编号用于构件定位。
- **引线标注**：将手写说明与具体部件绑定。
- **尺寸标注**：尺寸线、基准线、角度/弧线参照用于约束构件位置和几何关系。
- **重复节段表达**：尾部多个相似组件沿曲线排列，呈现连续构造和重复单元。
- **局部放射线/扇形辅助构造**：帮助表达某一局部的几何展开或构件位置。

图面没有可确认的统计样本、频数、百分比、平均值或数据计算图。尺寸标注可能涉及长度、角度、间距或曲率，但低清图无法确认具体单位与数值。不可将其当作比例准确的工程施工图，也不可根据扫描图像像素自行反推真实尺寸。

## C｜视觉编码
- **点**：圆圈字母、数字编号和连接位置作为局部定位锚点。
- **线**：轮廓线定义雕塑外形；引线绑定注释与部件；尺寸线/辅助线说明几何关系；重复线条表现构件排列。
- **面**：局部阴影和排线形成构件体积感及前后层次；阴影主要是手绘表达，不应视为数量编码。
- **体**：透视、遮挡、阴影和机械零件的轮廓共同建立立体构造想象；图面不是严格的三视图或可直接加工的实体模型。
- **符号**：A–E 与尾部编号构成索引系统；齿轮、铰接和钩状轮廓以形态提示机械构件。
- **色彩**：黑白/灰度手绘，依靠线条密度、粗细、明暗和留白区分部件与空间层次。
- **文字**：手写注释围绕主体分布，标题、项目委托方、作者和日期形成署名信息层。
- **尺度**：尺寸辅助线与编号把艺术造型转化为可讨论的构造对象；尺寸单位与比例精度待原件确认。

## E｜视觉叙事架构

本图的阅读方式不是统计结论叙事，而是从整体造型进入构件细节的技术说明：
1. **先识别整体对象**：标题和海马形态建立作品主题。
2. **理解造型骨架**：沿主体曲线观察头部、躯干与卷曲尾部的整体关系。
3. **定位局部构件**：通过 A–E 和数字编号找到被讨论的组件。
4. **读取构造约束**：沿尺寸线、基准线和引线阅读部件位置及几何关系。
5. **查看文字说明**：将手写注释与对应构件联系，理解设计意图。
6. **确认项目属性**：通过委托方、作者和日期识别这是一份特定项目的设计图面。

核心叙事可概括为：**整体造型 → 构成分区 → 构件定位 → 几何约束 → 制作说明**。

## 4. 本案例可提炼的设计观察

以下为单案例观察，需后续更多技术图解案例验证：
1. **整体形态作为索引底图**：先让读者识别完整对象，再通过局部标记深入构件。
2. **编号与引线共同定位**：圆圈编号建立索引，引线将编号/文字绑定到确切部件。
3. **尺寸线与造型线分工**：外轮廓表达形态，尺寸线表达几何约束，二者不应混淆。
4. **重复构件表达结构节奏**：尾部重复节段使复杂造型具有可识别的构成规律。
5. **手稿质感不等于信息随意**：即使采用自由手绘，标记、引线、尺寸和批注仍需形成稳定的阅读系统。
6. **艺术造型与科学解剖必须区分**：借用生物外形不代表作品在解释真实生物结构。
