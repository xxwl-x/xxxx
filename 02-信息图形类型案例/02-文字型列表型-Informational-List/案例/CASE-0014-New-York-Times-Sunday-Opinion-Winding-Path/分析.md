## 核心分类判断

本案例与 CASE-0013 同属文字型／列表型这一表现形式，但它不是“项目清单”。它属于**长篇文字分栏型（editorial text-dominant layout）**：三组文章标题、作者和多段正文是信息实体，黑白概念插画负责建立重点与组织阅读节奏。图面阅读的主要任务是读文章，而不是解读统计数据。

五大逻辑中选**编目型**，依据是页面以多个并列文章为条目，每个条目有标题、作者、正文、栏目/版面位置；文章之间不存在明确的父子归属、时间先后或空间定位关系。若把中央文章视为视觉上的重点，并不意味着左右文章在数据结构上从属于它。

## A｜基本的数据逻辑

主结构：报刊版面（page）→ 文章条目（article）→ 标题、署名、正文段落等内容属性（fields）。
- 页面：一页 Sunday Opinion。
- 文章集合：图面可辨认至少三组独立文章（左、中、右）。
- 条目属性：文章标题、作者署名、正文、段落、栏位、可能的引言模块。
- 视觉强调：中央文章及插画被显著放大，但这是编辑优先级而非数据等级。
- 图形属性：中央黑色大区域与蜿蜒白色形状作为独立的视觉内容单元。

这张图的最小记录单元宜为“一篇文章”，段落属于正文层内部结构。图面不提供可量化的统计值，因此不要为其构造虚假的频数、比例或时间序列。

## B｜统计图形、统计方法与计算

**无可辨认的统计图表或统计计算。**
- 左右大量正文使用传统报纸细窄分栏。
- 中央黑白插画不是流向图、桑基图、时间轴或数据趋势图，虽然白色路径呈蜿蜒曲线，但未见数值尺度、可计算的路径变量或节点属性。
- 强视觉隐喻中的曲线应解释为造型/叙事引导，不可当作真实测量曲线。
- 不能从黑色面积或白色曲线宽度推断任何比例或风险数值。
- 该案例证明“文字型信息图形”可以主要依靠编辑结构与隐喻插画完成信息传达，而不包含统计图。

## C｜视觉编码

| 视觉变量 | 图面具体应用 | 语义／效果 |
|---|---|---|
| 点 | 小字、标点、局部注释位置 | 文字构成细节；无数量编码 |
| 线 | 分栏边界、标题下方的隐性对齐线、中央长曲折白线 | 建立方向和视觉节奏；曲线为隐喻，不是统计路径 |
| 面 | 大片黑色几何/绘画区域与白色负空间 | 强烈对比，使中央文章成为页面第一视觉焦点 |
| 体 | 底部小房屋剪影、上方物体/地貌轮廓 | 提供叙事象征，非数量或真实地形 |
| 符号 | 小房屋、蜿蜒路径、黑色块中的形态 | 与中央评论主题形成概念联想；具体隐喻含义不应强作唯一解读 |
| 色彩 | 近乎全黑白灰 | 以黑白反差取代多色分类；保持报纸风格和阅读对比 |
| 字体 | 报头、文章大标题、作者署名、正文、引句不同字号与粗细 | 帮助快速识别文章边界、主次与阅读顺序 |
| 空间 | 左中右三大文章区，中央穿插插画与文字盒 | 让文字和图形相互嵌入而非简单图上文下 |

中央白色蜿蜒形状穿过黑色区域，连续连接多个视觉区域，引导视线纵向移动；它承担的是**隐喻和阅读引导**，不是数字可视化。

## D｜数据／信息架构

推荐将作品作为编辑页面进行结构化记录：

- `page`：page_id、publication、section、issue_date、page_number、source_image。
- `article`：article_id、page_id、title、byline、column_position、body_text、lead_text。
- `visual_element`：element_id、page_id、related_article_id、element_type、description、visual_role。
- `layout_relation`：relation_id、from_element_id、to_element_id、relation_type、notes。

目前只可靠抄录三篇大标题和对应的左／中／右位置；作者姓名、完整正文、页码与日期暂不转录。结构化表格是分析模型而不是原始数字数据集。

信息层级：报纸版面和栏目名称 → 三组文章标题 → 作者／引言 → 正文多栏 → 局部提示框。中央大插画优先抓取注意力，不意味着三个主题是时间、地点或因果序列。

## E｜视觉叙事架构

1. **报纸品牌与栏目框架**：顶部较小的报头和版块信息，建立“评论版”的阅读情境。
2. **横向扫视文章标题**：左、中、右三个题目让读者选择阅读入口。
3. **中央视觉冲击**：大片黑底与白色蜿蜒线，制造强对比和第一注视点，突出中央评论主题。
4. **图文交错推进**：读者可沿中央曲线向下移动，也可跳转至左右独立文章的正文列。
5. **内容深入阅读**：正文依靠报纸分栏及排版层级完成持续的线性阅读。

全页阅读可跳读，而单篇文章的正文通常需要按段落顺序阅读：这是两个层级不同的阅读逻辑，不应混为“全图时间轴”。

### 阶段性认识
- “文字型／列表型”是较宽的表现形式，既包含短条目清单，也包含长篇编辑文字型版面。
- 是否存在统计图不能作为文字型分类的必要条件。
- 视觉主角可以是人物拼图，也可以是抽象概念插画，但仍须判断谁承担信息内容。
- 页面级跳读与文章内部顺序阅读应分开记录。
- 不以视觉面积大小直接推断数据层级或逻辑归属。
