# CASE-0014｜数据字典

## 数据边界
`基础数据集.csv` 只包含 3 条在上传图像中可辨认的文章标题，**不是出版物的原始数据集或报刊全文**。不收录无法可靠确认的发表日期、作者、正文与数字。本案不存在可从图中确认的统计量值。

| 字段 | 类型 | 含义 |
|---|---|---|
| record_id | string | 知识库记录唯一 ID |
| record_type | string | article 表示一篇可独立阅读的文章 |
| title | string | 可辨认的文章标题 |
| publication | string | 图面报刊署名 |
| section | string | 图面栏目 |
| page_region | string | 页面左／中／右主要位置 |
| verification_status | string | 可直接辨认标题的记录状态 |

建议扩展 `visual_elements.csv` 记录黑色面、白色路径、房屋形态和注释框的视觉作用；如取得高清原版，可补充署名和全文索引，但不应把文章段落与文章记录混为一个不区分粒度的表。
