# CASE-0013 数据字典

- 文件：基础数据集.csv
- 记录数：4 行，均为从图面直接可辨认的成员名称。
- 粒度：一条可核验的对象属性事实；非原始完整数据表。
- 未收录歌曲清单和模糊的统计数字，不能臆造。

| 字段 | 类型 | 说明 |
|---|---|---|
| record_id | string | 唯一键 |
| record_type | string | 数据对象类型，如 member、work、event、metric |
| entity_name | string | 对象名称 |
| category | string | 主题类别 |
| attribute_name | string | 属性字段 |
| attribute_value | string | 可读的属性值 |
| unit | string | 数量单位，非数量留空 |
| source_location | string | 图面位置 |
| verification_status | string | 转录核验状态 |

后续高清图片恢复后，可分别建立 works.csv、events.csv 和 metrics.csv。需保存作品组别、年份、图表量值及图例口径；避免将不同粒度的数据混写在一张表中。
