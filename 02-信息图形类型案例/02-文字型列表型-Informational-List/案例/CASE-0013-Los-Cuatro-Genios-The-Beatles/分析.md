- 主题：披头士乐队四位成员、音乐作品、历史与统计。
- 语言：西班牙语。
- 来源：用户本次对话上传的作品图片。

- 主要表现形式：**02 文字型／列表型（Informational / List Infographics）**。
- 五大基础组织逻辑：**编目型（主题—人物/作品类别—属性）**。
- 辅助表现：局部饼图、横向条形图、年份事件序列、主题插画。

## 2. 主分类判断
本图以文字解释和条目索引为全页信息骨架。中央的黑白拼接肖像统一四位成员的形象，左右分别列出 JOHN LENNON、PAUL McCARTNEY、RINGO STARR、GEORGE HARRISON，并配有独立短文；画面中下方用统计模块、年份序列、艺术插画及底部两组密集列表补充主题知识。

它不是以统一坐标轴组织的统计图，也不是由先后事件主导的时间轴；图表是插入式补充信息。列表与人物分组并列，因此五大主逻辑是**编目型**。底部列表即使按某种顺序排列，也不能在未核实排序标准前断定其为排名。

## A｜基本的数据逻辑
- 主题实体：The Beatles。
- 人物条目集合：John Lennon、Paul McCartney、Ringo Starr、George Harrison。
- 作品/歌曲条目：底部左右多行的作品清单，具体标题和列结构待高清图核验。
- 年代事件：中部局部年份事件序列，作为编年辅助模块。
- 分类统计指标：饼图及横条图的相关数据，指标名、分母和数值须核对图例后才能转录。

建议用独立的 members、works、events、metrics 四张逻辑表，而不是把成员简介、歌曲和百分比混写为单表的一行。人物与作品可以建立关联，但当前截图不足以确认完整关系。

## B｜统计图形、计算方式
1. **饼图/构成图**：顶部或中部可辨认圆形扇区图，用于表达局部构成；分母、类别标签和精确百分比待核验。
2. **横向条形图**：右侧中部存在红色水平条形比较，类别、刻度、单位与数值待核验。
3. **局部年份事件序列**：中部人物剪影及时间/阶段标记呈现历史变化，是局部模块而非全图主轴。
4. **多列条目列表**：底部两块以一行一个记录组织作品或相关项目。列表用于查找，不自动代表数值统计。
5. **人物介绍**：以分类和文字说明组织，不需要数值统计。

不从模糊图片中补造歌曲名称、年份、百分比、排名及计算公式。不能因为画面出现几个图表就直接归为混合型主类。

## C｜视觉编码
| 通道 | 图面观察 | 信息作用 |
|---|---|---|
| 点 | 图例记号及小型符号 | 局部识别、提示阅读 |
| 线 | 模块边界、对齐参照及时间连线 | 分隔、引导与局部顺序 |
| 面 | 饼图扇区、列表交替色带与统计条 | 表达局部构成、比较或辅助辨行 |
| 体 | 中央拼接肖像及黄色潜水艇插画 | 主题识别与叙事情境，非数量 |
| 符号 | 乐队标识、成员轮廓、人物剪影 | 对象识别及主题连接 |
| 色彩 | 暖白纸色、黑白肖像、红色、橙绿条带 | 标题强调、列表分组及时代氛围 |
| 字体 | 大写西班牙文标题、成员名、正文与表格小字 | 建立标题—分类—正文—条目的信息层次 |

中央肖像虽然面积最大，但并非主要数据载体。复古纸张纹理和潜水艇图像是主题化视觉语言，不可当作统计量。

## D｜数据／信息架构
- 顶层：主标题 LOS CUATRO GENIOS 与 THE BEATLES 标识。
- 第二层：四个成员介绍模块，左右围绕中央肖像分布。
- 第三层：统计图、历史节点、主题插画等专题补充。
- 第四层：底部两组多行、多列的作品/相关条目表。

源数据重建建议：
- members：member_id、member_name、description、section_id。
- works：work_id、work_title、list_group、list_position、attributes。
- events：event_id、year、event_label。
- metrics：metric_id、chart_type、category、value、unit、denominator、source。

同一实体在多模块重复出现时建立关联键。不要把插画位置当作实际统计值。

## E｜视觉叙事架构
1. 标题和标识建立音乐主题。
2. 大型拼接人物肖像构成强视觉锚点。
3. 读者从四角人物模块了解四名成员，可自由跳读。
4. 读者转入中部饼图、条形图、年代事件和黄色潜水艇主题插画，获得补充信息。
5. 底部通过密集条目表做总结与作品检索。

这种阅读方式是**中心主题引导 + 并列人物简介 + 专题解释 + 列表检索**，整体可自由浏览，而不是不可逆的流程。

## 3. 从本案例提炼的阶段性设计方法
1. 大型主题肖像可以建立统一视觉识别，但不必承担统计值编码。
2. 并列人物用重复的姓名—符号—段落结构，便于横向扫描。
3. 长文本按主题分块，利用字号、字体粗细、位置和留白体现主次。
4. 密集表格可使用相对克制的交替底色及对齐提高辨行速度。
5. 饼图与条形图只作为局部专题的数据证据，不能代替目录的结构主轴。
6. 复古配色、做旧纹理和黄色潜水艇等主题元素表达文化背景，应服从阅读效率。

上述为**单个案例的观察**，不应直接等同于文字型/列表型的普遍必要条件。
