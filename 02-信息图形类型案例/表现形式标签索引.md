# 表现形式标签索引

本索引记录作品的视觉呈现方式与常见应用形式，作为案例检索和设计沟通用的多选标签。它不是第二套基础类型学；主分类仍必须从 01 的编年、层级、编目、字母表、地理五种逻辑中选择。

| 标签 | 识别重点 | 与基础逻辑的关系 |
|---|---|---|
| 混合型 Mixed Charts | 多种图表、符号和说明模块协同 | 可能组合多种逻辑 |
| 文字型/列表型 Informational / List | 条目、知识点、清单或说明文本 | 列表不自动等于编目型 |
| 时间轴型 Timeline | 时间节点、阶段带、历史序列 | 常与编年型相关，仍需检查真实顺序关系 |
| 示意图型 How-to | 对象结构、使用方式或原理说明 | 可辅助任何基础逻辑 |
| 流程图型 Process | 步骤、判断、分支和流转 | 需辨别过程顺序与一般关系 |
| 比较型 Comparison | 两个或多个对象/组别对照 | 常与编目或层级关系组合 |
| 地标/位置型 Location | 地点、地标、空间分布或区域特征 | 需确认空间关系是否主导信息 |
| 图片式 Photo-graphic | 摄影图像承担主要信息载体 | 图像表现手法，不决定数据逻辑 |
| 层级表现型 Hierarchical | 树状、嵌套、等级或上下位视觉结构 | 上下位为主关系时归层级型 |
| 单一图表型 Single Chart | 单一统计图形成为画面主体 | 基础逻辑取决于数据关系 |
| 文字可视化 Visualized Text | 文字大小、位置、形态承担信息编码 | 区分装饰排版与数据映射 |
| 解剖型 Anatomical | 整体对象与部件、器官、结构标注 | 可表现多种基础关系 |
| 视觉简历 Visual Resume | 个人经历、能力、作品与时间线可视化 | 常组合编年与编目逻辑 |
| 手绘型 Hand-drawn | 手绘线条、插画或草图风格 | 风格标签，不是数据逻辑 |
| 编年-编目复合型 Hybrid | 时间序列与类别分组同时重要 | 仍需选择一个主归属 |
| 三维型 3D | 立体模型、空间透视或三维场景 | 视觉维度，不自动等于地理逻辑 |
| 词云 Word Cloud | 词语按频次/权重形成视觉聚合 | 必须说明权重字段和计算口径 |

## 使用规则
每案选择一个基础逻辑主归属；选择一个主表现形式，可添加多个辅助形式；标签描述作品如何呈现，不替代对底层数据的判断；证据不足时标记疑似/待核验。
