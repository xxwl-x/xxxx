# CASE-0015｜Once upon a time in HK

## 2. 分类结论：为什么是时间轴型

全图的主导组织规则是**历史时间先后**。事件标题和年份沿多个横向带排列，读者沿每一带从左向右阅读，再转入下一带继续推进，最终从20世纪初走到2012年前后的现代香港。

画面包含大量人物、建筑、旗帜、车辆、船舶、飞机、公共交通和城市景观，但它们不是按类别独立编目，而是被放置在相应的年份/时期附近，作为历史事件的场景化解释。时间是骨架，插画是事件的视觉叙事。

### 与相邻类型的边界
- **不是文字型／列表型主类**：年份与事件不是供自由检索的并列目录；其位置和先后决定了阅读顺序。
- **不是地理图型**：虽然出现香港地标与城市建筑，但没有以地理坐标、地图位置或空间邻接关系组织全图。
- **不是混合统计图主类**：没有以统计坐标、比例尺度或数据系列作为主要骨架。
- **不是流程图型**：历史事件的先后并不等于操作步骤或因果流程。
- **不是单一连续比例尺的线性时间轴**：版面采用多行分段式布局，行内年份按时间推进；行间以视觉分带衔接。当前图片不足以证明节点间距严格按真实时间间隔比例绘制。

## 3. 版面结构观察
画面由约五条横向历史带构成。每条带内，事件年份与说明文字分布在场景插画上方或附近，插画沿带状区域连续展开。各带之间以横向基线/分隔关系形成版面秩序。

- **标题区**：顶部专题标识“110 Years Hong Kong”，主标题“Once upon a time in HK”，下方有导语。
- **第一条历史带**：以20世纪初的城市、交通与社会场景开启历史叙事，右侧延伸至20世纪前期事件。
- **第二条历史带**：继续呈现20世纪前半叶的政治、战争及城市生活相关事件。
- **第三条历史带**：转入战后社会与城市现代化、交通及文化生活场景。
- **第四条历史带**：呈现后期城市建设、公共交通、社会与政治变化。
- **第五条历史带**：延伸至1990年代、1997年前后及21世纪初的香港。
- **事件注释**：年份/年份区间、短标题和短段落与插画位置相互对应。
- **插画系统**：人物、建筑、车辆、船只、飞机、旗帜、烟雾和城市设施等共同构成历史情境。

以上“约五条带”是对上传图片可见版面的结构描述，不代表原始编辑文件中一定有五条独立时间数据轨道。

## A｜基本的数据逻辑

### 核心模型
编年型事件序列：**时间节点／时间区间 → 历史事件 → 事件说明与场景证据**。

建议最小数据单位为一条历史事件记录：
- event_id：事件唯一标识。
- start_year：事件开始年份或标注年份。
- end_year：事件结束年份（仅当图面明确给出年份区间时使用）。
- date_precision：精确年份、年份区间、约数或待核验。
- event_title：事件标题/短标签。
- event_description：图面说明文字。
- event_category：政治、战争、交通、城市建设、文化、社会生活等；只有在原文或明确证据支持时赋值。
- visual_scene_id：关联的场景插画。
- source_location：事件在图面中的位置。
- verification_status：转录核验状态。

### 时间字段的关键区别
1. **单年节点**：图面明确标出一个年份，记录为 start_year，不擅自补 end_year。
2. **年份区间**：图面明确出现起止年份时，保留原始区间；不能只用区间中点代替。
3. **跨年事件**：只有图面或可靠来源支持时才记为区间。
4. **时间不确定**：保留“约”“某年代”等原始精度，不将其伪装为精确年份。

图面大体从1903年至2012年展开。年份与事件是主要数据；人物、建筑和交通工具是事件属性及视觉证据，不是独立主轴。

## B｜借用的统计图形、计算方式与时间表现

本案例主要借用**编年时间轴和多行时间带**，不是传统统计图。

### 可识别的方法
- **多行时间轴**：将长时间跨度拆成多个水平阅读带，控制单行宽度和事件密度。
- **年份节点**：在每个事件附近标出年份或年份区间。
- **时间带分段**：以横向分隔线区分不同版面行，使阅读从一行推进到下一行。
- **事件注释**：将短标题和说明放在相应节点附近。
- **场景插画绑定**：让历史场景与相应事件/年代建立邻近关系。

### 不能从画面推断的数值
- 插画之间的水平距离不能直接当作真实年份间隔。
- 插画面积、人物数量、烟雾大小、建筑高度不能当作事件权重或统计数量。
- 节点多寡不能直接证明某一时期历史事件更多，可能受版面容量和编辑选择影响。
- 不能把贯穿场景的横向基线误认为数值坐标轴。

若后续要重绘为比例时间轴，应先取得所有事件年份，再明确比例尺、断轴、重叠处理和跨年事件编码。当前案例更适合定义为**编辑式分段时间带**，而非严格按年距比例绘制的连续坐标轴。

## C｜视觉编码

| 通道 | 图面使用方式 | 信息作用与注意事项 |
|---|---|---|
| 点 | 年份文字、事件位置及局部引线端点 | 定位事件；当前图面未必使用统一圆点节点 |
| 线 | 多条横向基线/分隔线、文字引线 | 维持每行时间推进和版面分区；不表示因果 |
| 面 | 每行历史场景带及其留白区域 | 将长时间跨度拆成可阅读区段 |
| 体 | 人物、建筑、车辆、船舶、飞机、城市设施 | 重建历史环境；不代表数量或统计值 |
| 符号 | 旗帜、交通工具、公共设施、时代物件 | 让读者快速识别时代与事件语境 |
| 色彩 | 以低饱和、历史插画色彩为主，局部鲜明旗帜/车辆色 | 统一历史氛围，同时突出少数视觉焦点 |
| 文字 | 年份、事件标题、短段落、总标题和导语 | 为场景提供时间锚点和事实解释 |
| 空间 | 多行横向带、插画与文字上下错落 | 将时间序列转译为连续的历史长卷 |

### 视觉层级
1. 专题名称和主标题：建立“香港110年”的主题。
2. 场景插画：形成主要视觉吸引力和时代感。
3. 年份：提供精确的时间定位。
4. 事件标题和短说明：解释插画对应的历史事实。
5. 细节物件：丰富历史情境，但不抢夺时间主轴。

### 重要编码原则
插画细节可以高度丰富，但必须让年份、事件和插画之间的对应关系清楚。色彩、人物比例和场景面积服务于叙事，不自动承载量化含义。

## E｜视觉叙事架构

### 主叙事
**历史起点 → 早期城市生活 → 社会与政治变迁 → 战争与战后重建 → 城市现代化 → 1997前后及当代香港**。

这是对全图宏观主题的归纳；具体事件之间是否存在因果关系，须由文字来源证明，不能只凭先后顺序断定。

### 阅读路径
1. **主题进入**：从“110 Years Hong Kong”和“Once upon a time in HK”识别历史专题。
2. **时间定位**：从第一条时间带的早期年份进入。
3. **场景理解**：通过插画观察当时的建筑、交通、人物服饰和社会环境。
4. **事实确认**：阅读相邻年份、事件标题和短说明。
5. **行间推进**：沿每条横向时间带阅读，再进入下一条带。
6. **抵达当代**：在底部的现代香港场景中完成长时间跨度的回顾。

### 叙事优势
- 把抽象历史年份转化为具体可感知的时代场景。
- 以连续横向场景降低长时间跨度的理解难度。
- 年份与短文提供事实锚点，插画提供情境记忆。
- 多行布局在有限页面内容纳大量事件。

### 叙事风险
- 插画复杂、事件密集时，读者可能难以快速确认某幅场景对应哪个年份。
- 行与行之间的跳转规则如果不够明确，可能造成时间顺序误读。
- 读者可能把插画尺寸理解为事件重要性，实际未必如此。
- 历史图像容易被当作严格写实记录，需区分插画重构与史料照片。

## 4. 本案例可提炼的设计方法

1. **多行时间带**：长时间轴可以分行，而不是强行塞进单条水平轴；必须维持清晰的行间阅读顺序。
2. **事件—场景绑定**：每个插画场景应能找到相应时间节点和文字说明。
3. **时间文字独立编码**：年份要在复杂插画背景中保持足够对比和可读性。
4. **以插画表现时代环境**：建筑、交通、服饰和生活物件共同建立时代识别。
5. **事件密度与画面节奏控制**：重大场景可使用较大视觉空间，但不要暗示未经数据支持的数量或权重。
6. **事实与重构分开**：插画是对历史环境的视觉再现，事件事实仍由文字、出处和年份支撑。
7. **分段不等于比例**：多行分段是排版策略；除非明确使用真实时间比例，否则不把画面距离当成时间间隔。

这些是从本案例提炼的设计观察，后续需与更多历史时间轴案例比较，才能写成稳定的通用原则。
