# CASE-0015｜数据字典

## 文件说明
- 文件：基础数据集.csv
- 当前记录：5条版面时间带范围记录（不是逐条历史事件数据库）。
- 这些范围是根据图面中可见年份及行带分布概括的版面分析结果；尚未逐一核实所有事件。
- 事件标题、描述、插画内容和精确起止年份未能从低清图完整转录，暂留空，不猜写。

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| record_id | string | — | 当前记录 ID |
| record_type | string | — | band 表示版面时间带，不是单个历史事件 |
| start_year | integer | 年 | 该时间带可见的概括起始年份 |
| end_year | integer | 年 | 该时间带可见的概括结束年份 |
| date_label_original | string | — | 对版面范围的概括标记，非原图逐字标签 |
| timeline_band | integer | — | 版面从上到下的时间带编号 |
| event_title | string | — | 事件标题，待高清图转录 |
| event_description | string | — | 事件文字说明，待高清图转录 |
| visual_scene | string | — | 场景插画描述，待逐项整理 |
| verification_status | string | — | 当前记录核验状态 |

## 后续逐事件建表
正式数据集应一行一个事件，而非一行一个横向时间带。建议事件表字段：
event_id, start_year, end_year, date_precision, event_title, event_description, event_category, timeline_band, scene_id, source_location, verification_status。

## 数据质量规则
1. 原图给出单一年份时不自行补结束年份。
2. 原图给出年份区间时保留区间，不用中点替代。
3. 对模糊文字标注“待核验”，不按历史常识补写。
4. 插画面积、人物数量、场景密度不当作统计数值。
5. 多行时间带的行序与年份区间是版面组织字段，不等于真实时间间隔比例。
