## 2. 分类结论：环形时间轴型

本图的主导信息关系是格罗皮乌斯相关事件沿时间先后展开。红色粗线构成近似环形/开放式圆弧时间主轴，年份节点沿弧线分布，从右上方的早期年份沿右侧、底部、左侧推进至左上方的末端箭头。人物肖像位于中心，时间线围绕人物展开。

因此，它不是因为“画面是圆形”才归为时间轴，而是因为**年份与事件的先后关系决定了读者的主要阅读路径**。圆环是时间顺序的空间化排布方式。

### 分类边界
- **主类不是人物简历/视觉简历**：人物肖像虽是视觉中心，但主体内容由连续年份节点和作品/经历事件构成，读者需要沿时间顺序理解人物发展。
- **主类不是地理图型**：世界地图及 UK、Germany、USA 等地理标记提供地点背景，但并非以地理位置作为全图主排序规则。
- **主类不是建筑作品编目**：外围建筑、家具/设计物件是按时间节点关联的成果，不是完全独立的类别目录。
- **主类不是层级型**：人物、学校、建筑之间有关系，但画面主要阅读顺序仍由时间驱动。
- **辅助标签**：人物主题、地理背景、建筑作品图像展示；是否另加视觉简历标签取决于仓库标签体系的具体定义，不改变本案例的时间轴主归属。

## 3. 版面与阅读结构观察

### 3.1 中心—环形—外围三层结构
1. **中心主体**：格罗皮乌斯大幅黑白肖像，是最强视觉锚点。
2. **中间地理层**：浅灰世界地图，标出 UK、Germany、USA 等地域，并出现多个地点标记和小型人物头像。
3. **环形时间层**：红色粗弧线环绕中心，年份与节点沿线排列，形成主要阅读路径。
4. **外围事件层**：画面四周放置年份标题、建筑照片、设计物件图像及文字说明；红色虚线将外围卡片与环形主轴上的相关年份连接。

### 3.2 时间阅读方向
从图面可见的年份位置判断，主轴大致从右上方的 1883.5.18 开始，沿右侧向下经过 1900年代、1910年代，再沿底部进入1920—1930年代，继而沿左侧向上延伸至1940—1960年代，最后指向左上端的末端箭头。

注意：这是按版面节点位置归纳的阅读方向。具体每个节点对应的事件标题和精确日期仍需高清原版核验。

### 3.3 外围事件卡片
外围卡片将部分年份放大为红色大号数字，并配有建筑/物件图片和短说明。可辨识的年份包括1910、1920、1925、1926、1928、1936、1937、1958、1959、1963等。外围卡片并不是第二条独立时间轴，而是对主轴特定节点的扩展说明。

### 3.4 人物关系层
格罗皮乌斯肖像周围出现多个人物小肖像和简短标签，提供人物关系或同一历史语境下的重要人物线索。由于小字不可完全辨识，不能在本档案中擅自认定每个头像的姓名及其与格罗皮乌斯的具体关系。

## B｜借用的统计图形、计算方式与时间表现

本案例没有明显的数值统计图表。其主要借用的是**环形时间轴（Circular/Radial Timeline）**，并结合地图和事件卡片。

### 可识别的图形方法
1. **环形/弧形时间轴**：把长时间跨度安排在围绕中心人物的弧线上。
2. **节点标记**：以小圆点、菱形或线上的标记指示时间节点。
3. **开放式箭头**：弧线末端箭头提示时间方向和序列终点。
4. **外围事件卡片**：将重要年份从主轴中抽出，配合大号年份、图片和短说明。
5. **虚线连接**：从主轴节点引出外围卡片，建立事件与作品图像之间的对应关系。
6. **地图定位**：用国家/地区标签和圆点标出相关地理背景。

### 时间计算与比例判断
- 图中年份节点沿弧线排列，但节点间距不应直接认定为严格按真实年份差值成比例。
- 事件卡片大小由版面和叙事重要性控制，不是时间长度。
- 地图圆点大小和人物头像数量没有足够图例证据支持数量解释。
- 不存在可确认的数值纵轴、统计单位或连续数据系列，因此不应把红色弧线理解为数值折线图。

若要重建真实比例环形时间轴，需取得全部事件日期，计算相对于起始时间的角度位置，例如 angle = (event_time - start_time) / total_duration × angular_span，并说明断轴、日期精度和重叠处理。当前图面更接近编辑设计的编年布局，尚无证据证明其角度与真实时间间隔严格成比例。

### 视觉层级
1. BAUHAUS 主标题：建立主题识别。
2. 格罗皮乌斯大幅肖像：明确人物中心。
3. 红色环形主轴：建立主要阅读路线。
4. 红色大号年份：帮助快速定位关键节点。
5. 外围建筑/设计物件图片：提供作品证据与场景信息。
6. 地图和小头像：补充地点、人物及关联背景。
7. 小字号说明：承担细节解释。

### 视觉优化原则
- 主时间线应在地图与肖像背景上保持足够对比。
- 外围引线应尽量避免交叉，并保证每张卡片可以明确追溯到主轴节点。
- 环形时间线的起点、终点和阅读方向必须清晰，避免读者误以为是循环过程。
- 地图底色应弱化，避免与主轴争夺视觉焦点。
- 人物小头像必须配姓名/关系说明；无法辨认时不应仅靠肖像让读者猜测。
- 建筑图像应与时间节点准确绑定，不应让图片年代和事件年份混淆。

## E｜视觉叙事架构

### 主叙事
**人物身份建立 → 出生/早期经历 → 教育与职业发展 → 包豪斯及相关作品/机构节点 → 地域与人物关系展开 → 后期经历与时间线终点**。

这是根据页面结构归纳的叙事框架，不代表每个阶段的具体事件已全部转录。

### 阅读路径
1. **主题识别**：从 BAUHAUS 标题和 Walter Gropius 人物介绍进入。
2. **人物锚定**：通过中心肖像确认叙事主角。
3. **时间起点**：从右上方的早期日期节点进入。
4. **环形推进**：沿红色弧线依次读取年份和节点。
5. **事件展开**：遇到外围红色年份卡片时，沿虚线查看建筑/设计作品图片与说明。
6. **空间补充**：结合世界地图理解人物经历与相关地点。
7. **人物关系补充**：查看中心肖像周围的小头像和标签。
8. **抵达末端**：沿弧线继续至左上方箭头，完成时间序列阅读。

### 叙事优势
- 人物肖像与环形时间轴结合，主体明确且视觉记忆点强。
- 环形布局让长时间跨度围绕人物展开，避免传统横向时间轴过长。
- 外围作品图像将抽象履历转化为具体建筑与设计成果。
- 地图将人物经历与地域联系结合，增加空间维度。
- 大号红色年份和红色主轴构成统一的视觉导航系统。

### 叙事风险
- 环形阅读方向若缺少清楚的起点/终点提示，可能造成顺逆时针误读。
- 中央肖像、地图、红色主轴和外围图片同时争夺注意力，信息层级容易拥挤。
- 外围引线较多，若连接点不清晰，读者可能无法判断某个作品对应哪一年。
- 地图位置与时间事件若没有明确连接说明，容易被误认为是迁移路线或地理数量分布。
- 人物小头像和作品图像的小字说明在当前分辨率下难以辨认，不能据此确认所有姓名与事件。

## 4. 可提炼的设计方法

1. **人物中心环形时间轴**：适合人物经历、职业发展和作品生涯等单一主体的长时段叙事。
2. **主轴与事件卡片分层**：主轴只保留年份和关键节点，复杂说明放在外围卡片。
3. **时间—作品绑定**：建筑/设计作品通过引线关联到创作或历史节点。
4. **地图作为第二维度**：在时间序列之外增加地域信息，但地图应保持辅助地位。
5. **人物关系作为补充网络**：小头像能增加人物关系维度，但必须提供清晰姓名和关系标签。
6. **环形时间轴必须有方向**：明确起点、终点、顺时针/逆时针路径；开放式弧线比闭合圆环更容易表达时间不可逆。
7. **颜色承担导航而非装饰**：用单一强调色贯穿主轴、年份和引线，建立统一的视觉语法。
8. **避免伪比例**：弧线节点间距、外围卡片面积和地图圆点大小都不能在缺乏图例时被解释为定量尺度。
