## 分类理由
红色弧形主轴沿年份节点展开，构成主要阅读路径；中央人物肖像建立叙事主体，地图、人物头像和外围建筑/设计作品卡片作为时间事件的补充信息。因此主表现归为时间轴型，底层数据逻辑为编年型。图面弧线间距不应在缺少比例尺证据时解释为真实时间间隔比例。
