## 分类理由

本案例按用户校正归入文字可视化：品牌名称、类别文字、排名与销售额标签构成主要信息内容，气泡面积和类别色承担文字信息的组织、索引与量化辅助。气泡图是表达载体，不改变本案例在本知识库中的文字可视化主标签。

作品把美国快餐连锁品牌按 Burger、Chicken、Snack、Global、Sandwich、Pizza 等类别分组，并以圆形大小比较各品牌2021年美国销售额。类别分组构成编目型的对象—类别结构；圆面积承担量化比较。它不是地图，也不是时间轴。单一气泡图是主要统计证据，因此标记10号单一图表型为辅助标签；图中品牌标志、装饰插画与分区文字并不构成多种独立统计图表。
