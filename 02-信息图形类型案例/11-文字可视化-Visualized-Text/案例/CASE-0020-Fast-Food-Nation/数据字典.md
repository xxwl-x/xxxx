# CASE-0020｜数据字典

## 文件：基础数据集.csv

一行代表一个快餐连锁品牌。当前仅为字段模板，未从低分辨率图片推测填入50家品牌的全部数据。

| 字段 | 类型 | 含义 |
|---|---|---|
| brand_id | string | 品牌唯一编号 |
| brand_name | string | 品牌名称 |
| category_id | string | 对应类别编号 |
| us_sales_2021 | number | 2021年美国销售额；需核实原始口径 |
| currency_unit | string | 金额单位 |
| rank | integer | 图中排名 |
| logo_label | string | 图中标识或简称 |
| source_name | string | 数据来源 |
| sales_definition | string | systemwide sales等统计口径说明 |
| evidence_status | string | 图面可读／来源待核验／待转录 |

## 口径约束
- 图面说明指向 QSR Magazine 的 systemwide sales ranking 与2021年美国销售额。
- 复核原始来源前，不应将金额单位、系统销售额定义和品牌排名作为完全核验事实。
- 类别色用于分组，不代表销售额区间。
- 气泡面积映射数值；不能用直径直接等比例映射。
