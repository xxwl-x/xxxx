# CASE-0010 数据字典

## 文件状态
- 文件：基础数据集.csv
- 当前状态：仅建立字段模板，0 条观测记录。
- 原因：图面小字和数字无法全部可靠辨认；未获得原始数据或高清出版页面。
- 最小记录单位：一种图面明确标示的人物/兵马俑类型，而非一张头像或一个插画像素。
- 不得将插画尺寸、人物出现次数直接当作实际数量。

## 字段说明

| 字段 | 类型 | 含义 |
|---|---|---|
| figure_type_id | string | 仓库内人物类型唯一标识 |
| type_name_as_shown | string | 按图面转录的类别名称 |
| role_category | string | 图面明确说明的角色/兵种类别 |
| pose | string | 图面呈现的姿态 |
| headwear_or_hairstyle | string | 头饰或发式特征 |
| visual_features | string | 可观察到的人物/装备特征 |
| source_note | string | 图面位置或经核验的资料来源 |

装备、军阶、考古制作信息应分别建立独立数据表；不要将不同记录粒度强行合并到本 CSV。
