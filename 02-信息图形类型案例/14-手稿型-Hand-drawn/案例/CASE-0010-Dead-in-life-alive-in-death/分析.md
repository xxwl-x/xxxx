# CASE-0010｜Dead in life, alive in death

## 1. 基本信息与证据边界
- 图面标题：Dead in life, alive in death
- 中文工作译名：生时已逝，死后永生
- 媒体署名：South China Morning Post
- 图面日期：2014-03-29
- 主题对象：秦始皇陵兵马俑及相关考古、军事与制作知识
- 本分析依据用户于 2026-11-23 提供的图像。小字号注释和数字无法全部可靠辨认，因此不转录不确定的名称、数量或比例。
- 原图为第三方出版作品；本次只提交分析与空白数据模板，不上传原图二进制。

## 2. 类型归属
- **五大基础逻辑主归属：编目型。** 主体围绕兵马俑人物/兵种类型、面部与发式、服饰装备、姿态及制作信息展开分类和属性说明，回答“有哪些类型、各自有什么特征”。
- **辅助逻辑：层级型。** 图中军事等级/军阶模块表达等级差异；它是局部分类关系，不取代全图的编目主结构。
- **辅助逻辑：地理图型。** 左上角小地图提供考古地点的空间背景。
- **编年型不是主逻辑。** 历史背景有时间信息，但全图没有以时间序列组织主体内容。
- **表现标签：14 手稿型 Hand-drawn。** 写实手绘人物、头像、装备及场景是主要视觉载体；01 混合型可作为辅助标签，指插画、地图、示意图、标注与小型统计图的组合。
- 不将人物插画本身当成定量统计；不因中央人物画得较大就推断其军阶或数量。

## A｜基本数据逻辑
核心对象是兵马俑个体/类型及其可观察属性。图面可辨识的信息维度包括：
1. 人物/兵种身份类别（如将军、士兵、弓箭手等图面标签）。
2. 头部与面部特征（发式、头饰、面貌差异）。
3. 姿态与角色（站立、跪姿、持械等）。
4. 服饰、盔甲与装备。
5. 军事等级/军阶关系。
6. 制作、彩绘、修复或考古发现相关说明。
7. 历史背景与发现地点。

主导关系是“对象—类别—属性”的编目结构。军阶可单独表示为有序等级；人物类型与军阶不能在未经证实的情况下合并成同一分类轴。图面中的人物画像用于呈现类型差异，并不代表真实兵种比例。

## B｜统计图形与计算方式
- **人物头像/人物图符阵列**：顶部、两侧和底部排列不同头像或人物形象，用于展示可辨识的类型差异，主要是分类索引，不是自动可计数的样本阵列。
- **中央比例人物插画**：用较大的全身人物及周边人物姿态展示服装、盔甲和动作细节，属于说明性图解，不是以人物高度编码数值的统计图。
- **局部结构示意图**：右上区域的墓葬/空间示意用于解释位置或结构关系；精确空间比例需原始图例核验。
- **象形数量图示**：左下区域出现人物/动物等小图符与数量说明，属于图符辅助的数量呈现。图符代表的单位、统计口径和数字需高清原图核验，当前不计算或转录模糊数值。
- **等级示意**：右下军阶模块以人物/头饰等符号区分等级，属于序数/等级分类，不等同于连续数值统计。
- 本图没有足够证据证明所有插画尺寸按数量比例缩放。不得把插画面积、头像数量或视觉大小直接换算为兵马俑总数或军队构成比例。

## C｜视觉编码
| 通道 | 图面应用 | 作用与限制 |
|---|---|---|
| 点 | 头像、局部标记、图符 | 作为分类索引或注释定位；不是天然的数据观测点 |
| 线 | 引线、轮廓线、结构线 | 连接局部细节与文字说明；引线不表示流程 |
| 面 | 服装、盔甲、头饰及背景区域 | 区分人物部件和视觉模块 |
| 体/形态 | 全身陶俑、人物姿态、战车/器物形象 | 以可识别形态传递对象知识；不是三维数值编码 |
| 符号 | 人物小图符、军阶/装备符号 | 表达类别或等级；量化单位须由图例确认 |
| 色彩 | 米白、赭石、棕褐及局部彩绘色 | 建立考古文物质感，并突出局部服饰/装备信息 |
| 文字 | 人物身份、装备名称、历史注释和数字 | 补足图像不能独立表达的分类标准与事实 |

## D｜数据／信息架构
建议将源数据拆为独立表，避免把人物类型、装备和考古发现等不同粒度混在同一张表中。

### 表 1：人物/兵马俑类型表
一行代表一种经图面或可靠资料确认的人物类型。字段建议：figure_type_id、type_name_as_shown、role_category、pose、headwear_or_hairstyle、visual_features、source_note。

### 表 2：装备与服饰表
一行代表一种装备/服饰项目。字段建议：item_id、item_name_as_shown、item_category、description、associated_figure_type_id、source_note。

### 表 3：军阶/等级表
一行代表一个图面明确标出的等级类别。字段建议：rank_id、rank_name_as_shown、rank_order_if_verified、visual_marker、source_note。只有图面明确给出顺序时才填写等级序号。

### 表 4：考古与制作信息表
记录制作工艺、材料、彩绘、发现地点、考古说明等。字段建议：fact_id、topic、description_as_shown、location、period_if_verified、source_note。

### 信息展示层级
标题与历史导语 → 发现地点地图 → 中央人物视觉锚点 → 周边人物类型与装备细节 → 军阶/制作/数量补充模块 → 底部头像与面部特征索引。

当前 CSV 仅提供字段模板，不填入未经核实的图面数字或人物类别完整清单。

## E｜视觉叙事架构
1. 标题以“生时已逝，死后永生”提出历史与考古主题。
2. 简短背景文字及左上地图交代秦始皇陵兵马俑的历史/发现语境。
3. 中央大型人物插画建立视觉锚点，使读者先形成对陶俑形态的整体认知。
4. 周围头像、全身人物与装备细节从不同角度拆解人物类型、身份、姿态和服饰。
5. 军阶、制作工艺、墓葬结构及数量图示作为专题证据模块补充。
6. 底部和两侧的头像阵列回到人物差异，形成从整体人物到细节分类的知识阅读闭环。

这是以核心对象为中心的分类式知识叙事，而不是按年代推进的时间故事。

## 可复用设计方法
1. **中心主体式知识布局**：以一个大型代表性对象建立视觉锚点，周围布置分类与细节说明。
2. **肖像目录/形态索引**：用重复头像展示人物类型差异，适合人物、职业、物种和历史角色类主题。
3. **局部细节放大**：将头饰、盔甲、姿态和器物等细节与引线、文字关联。
4. **多尺度图像协同**：中央全身图说明整体，周边头像说明差异，小型结构图说明局部空间或制作知识。
5. **分类与等级分开编码**：人物类别属于名义分类，军阶属于序数关系，需使用不同的视觉组织方式。
6. **插画与统计分工**：插画承担识别和解释；只有有单位、有图例、有来源的图符或图表才承担数量编码。
