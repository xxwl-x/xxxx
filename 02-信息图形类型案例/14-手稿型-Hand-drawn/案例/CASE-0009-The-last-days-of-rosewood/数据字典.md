# CASE-0009 数据字典

## 文件状态
- 文件：基础数据集.csv
- 当前状态：仅建立空数据结构表头，**0 条观测记录**。
- 原因：用户提供的图像分辨率不足以可靠转录全部树种/动物名称、保护状态及数值；不得猜测或用外部常识填补图中未证实字段。
- 最小记录单位：一个物种/生态对象记录。
- 预计字段数：8 列。

## 字段说明

| 字段 | 类型 | 单位/值域 | 含义 |
|---|---|---|---|
| species_id | string | 唯一 ID | 仓库内物种记录标识；录入时生成 |
| common_name | string | 原图可辨认名称 | 图中常用名称；无法辨认则留空 |
| scientific_name | string | 学名 | 仅在原图或可靠来源核实后填写 |
| organism_group | string | tree / mammal / other | 对象类别；需有图面依据 |
| conservation_status_as_shown | string | 原图图例类别 | 按图中保护状态图例逐字转录 |
| population_or_resource_note | string | 原图注释 | 种群或资源信息；保留原口径 |
| geographic_range_as_shown | string | 原图注释 | 图中标注的分布区域 |
| source_note | string | 来源说明 | 图面转录/外部核验来源及页码或 URL |

## 其他数据
地图贸易流、年度进口量和资源变化圆形统计属于不同粒度，未混入本表。待获得可核验数据后，应分别建立贸易流 CSV 和年度统计 CSV，不能将不同观测单位放进同一张物种表。

## 来源与限制
- 来源图：用户于 2026-11-23 在对话中提供的 South China Morning Post 信息图。
- 具体物种、数值、计量单位及统计截止时间：部分无法辨认，待核验。
