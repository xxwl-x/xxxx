# CASE-0007｜Satellites network

## 基本信息
- 原标题：Satellites network
- 中文工作译名：卫星网络
- 发布媒体：South China Morning Post（图面署名）
- 图面日期：2014-12-29
- 主题：仍在运行的人造卫星的发射年代、轨道分布、用途和国家/地区分布
- 五大基础逻辑主归属：**层级型**（以卫星总体为中心，向轨道类别、用途类别及国家/地区等层级展开）
- 辅助基础逻辑：**编目型**（卫星按用途、轨道、所属国家/地区归类登记）；**编年型**（顶部按发射年份展示仍在运行的卫星）
- 主要表现标签：**09 层级表现型 Hierarchical**
- 辅助表现标签：**01 混合型 Mixed Charts**（主径向结构、时间序列、圆形比较统计组合）
- 原图状态：用户于 2026-11-23 在对话中提供；本次提交分析文档，未将第三方原图二进制复制入仓库。
- 证据边界：分析依据用户提供的图像；小字号卫星数量、年份和国家缩写未逐项转录，精确统计需高清原件/原始数据核验。

## A｜基本数据逻辑
作品围绕“仍在运行的卫星”建立多维分类结构。核心数据对象是单颗卫星或按图面口径汇总的卫星集合；重要属性包括轨道类型、运行用途、所属国家/组织、发射年份/仍在运行状态及数量。

主结构从卫星总体向外展开：**卫星总体 → 轨道类别（如低地球轨道、地球同步轨道、中地球轨道、椭圆轨道）→ 用途类别（商业、政府、军事、民用、混合等）→ 国家/组织分布**。具体轨道分组及其下层分支以图面标注为准。顶部时间序列从另一维度呈现仍在运行卫星的发射年代分布，底部圆形统计再按用途和国家汇总。

因此，本图不是单一树状目录，而是以层级分类为骨架、多个属性维度交叉展开的复合数据结构。连接线表达图中的分类/归属路径，不应误读为卫星之间的通信链路。

## B｜使用的统计图形与计算方式
1. **径向层级网络图 / Radial hierarchical diagram**：中央“Satellites network”作为总体主题，向不同轨道类型分支，再继续展开用途、国家/组织等子分类。
2. **比例圆 / Proportional circles**：主图中圆形节点的大小用于表达卫星数量；应依据图例所述的圆形面积编码原则理解，不能直接从圆的直径估算数量。
3. **时间序列圆点图**：顶部按年份排列卫星发射/仍在运行的年代信息，圆形大小与相应数量信息结合呈现。
4. **分类比例圆比较**：底部两组圆形统计分别比较仍在运行卫星的用途类别和国家/地区分布。
5. **数量汇总**：图面展示了不同轨道、用途和国家/组织的数量及百分比；因截图分辨率有限，本分析不重抄难以辨认的数值，也不重新计算占比。

需区分：图中线段主要承担层级连接与分组阅读功能；它不是标准通信网络图，也不能据此推断卫星间的物理连接关系。圆节点大小才是图面明确强调的数量编码。

## C｜视觉编码
- **点/圆形节点**：每个圆代表一个分类节点或卫星数量集合；圆形大小编码该节点对应的卫星数量。
- **线**：放射状连线连接总体、轨道和下级分类，表达分类路径/隶属关系；线段不代表通信链路。
- **位置**：围绕中心向外组织，利用空间分支区分轨道及其下属类别；节点之间的空间距离不应被当作真实轨道距离。
- **文字**：节点内标注类别名称与数量，旁侧标注国家/用途等细分数据；图例解释变量定义。
- **色彩**：主体采用黑底白色节点和细线，形成强烈对比；局部标签和底部比较图辅助区分数据分组。不要把装饰性差异解释为额外数据变量，除非图例明确说明。
- **版面**：顶部时间序列、中央径向层级主体、底部用途/国家圆形比较，构成三个互补阅读区。

## D｜数据／信息架构
建议建立可复核的卫星基础数据表，字段至少包括：
`satellite_id`、`satellite_name`（如可获得）、`launch_year`、`operational_status`、`orbit_class`、`use_category`、`country_or_operator`、`source`。

如果图面采用汇总值而非逐颗卫星记录，则另建汇总表，字段包括 `dimension`、`category`、`satellite_count`、`share`、`as_of_date`、`source`。逐颗卫星明细与汇总统计应分表保存，避免把集合数量误当成单颗卫星属性。

信息层级：
1. 主题与卫星总体；
2. 轨道分类；
3. 各轨道下的用途/国家或组织分布；
4. 顶部发射年份时间序列；
5. 底部用途与国家/地区汇总比较；
6. 图例、数据定义与来源。

## E｜视觉叙事架构
先以“Satellites network”建立卫星总体主题 → 通过径向结构将总体拆分为不同轨道类别 → 进一步展示轨道内部按用途、国家/组织划分的卫星数量 → 顶部补充卫星发射年代与当前运行情况 → 底部从用途和国家两个角度重新汇总 → 让读者从轨道、用途、国家和时间多个角度理解全球在轨卫星的构成。

## 值得提炼的设计方法
1. **中心—分支的径向层级表达**：将多层分类树转换为围绕中心主题展开的空间结构。
2. **节点面积编码数量**：通过比例圆承载不同分类集合的数量，同时用文字给出精确数值。
3. **多视图互补**：主图讲分类层级，顶部讲时间分布，底部讲用途与国家比较；不同视图共享同一数据主题。
4. **黑底高对比信息组织**：白色节点和细线强化复杂结构的可读性；需要依赖字号、留白和分区维持阅读秩序。
5. **防止图形语义混淆**：分类连接线不是通信链路，节点间距不是轨道距离，圆形面积也不能以直径代替。
