# 混合型信息图形（Mixed Charts）说明文档

## 当前定义依据

根据用户给出的分类说明，混合型信息图形不同于单纯的数据可视化：它对统计图形进行视觉叙事和视觉编码，并使用符号、ISO 图形与统计图形组合制作信息图形。

本说明文档只根据用户提供的案例图逐步归纳。单个案例观察到的特点先标记为“案例观察”，只有在更多案例中反复出现并得到支持后，才提升为较稳定的原则。

## 案例 001 的初步归纳（单案例观察）

### 1. 数据逻辑与图形组合

同一主题下并置多种数据/信息结构：
- 时间序列：香港历年出生数量变化。
- 时间节点：过去狗年及对应出生数据。
- 人口数值：配合圆形标记展示人口规模信息。
- 分类属性：五行、吉利/不吉利数字、颜色和方向。
- 关系结构：十二生肖之间的相合/关系类别。
- 多维预测：十二生肖 × 爱情/工作/财富/健康的预测矩阵。
- 人物索引：属狗名人、肖像与出生年份。

图形语法与数据性质对应：时间序列用面积图，关系用放射网络，多维比较用矩阵式小 multiples，分类规则用符号、数字和色块。

### 2. 视觉编码与叙事

- 大型主题插画作为整张图的视觉锚点，而不是数据比例编码。
- 生肖符号在关系图与预测矩阵中重复使用，帮助读者跨模块识别同一类别。
- 红/粉色在统计图和部分关系/预测图形中承担突出作用；每个模块仍需按自己的图例解释颜色，不假设全图色彩语义完全一致。
- 标题、主题插画和分区小标题形成主次层级；多个信息模块围绕同一主题展开，而不是强制组成单一线性阅读路径。
- 叙事大致从主题吸引、历史背景、文化知识、生肖关系、人物例证，延伸到当年预测。

### 3. 单案例可观察到的制作方法

- 先确定统一主题，再将主题拆成多个不同信息任务。
- 根据数据/信息结构选择不同图形，不把所有内容强行转成同一种统计图。
- 用重复的符号建立跨模块关联。
- 用大型主题插画建立视觉中心，用版面分区容纳高密度信息。
- 让统计图表、符号、肖像和说明文字共同参与叙事。

### 4. 证据边界

- 本案例图片为 642×1080，部分小字号数值和图例不可可靠辨认；精确数值暂不作为结论。
- 不能仅因出现图标就认定其为 ISO 标准图形。本案例可确认的是生肖符号、图标和人物肖像，尚无足够证据证明其使用了 ISO 标准图形体系。
- 运势图形的红/灰条带具体对应何种等级或量表，须以清晰图例复核，不推断其精确量化含义。

## 案例 002 的初步归纳（单案例观察）

### 1. 数据逻辑与图形组合

本案例并非单一数据表驱动，而是多种知识结构并置：
- 时间序列/历史序列：顶部弧形时间轴组织远古时间节点。
- 整体—部分结构：大型蟑螂插画与触角、口器、翅、腿和内部器官等局部结构相互对应。
- 结构—功能关系：器官结构与感知、呼吸、进食、移动等功能说明相连接。
- 分类比较关系：不同蟑螂种类及其体型/外观进行比较。
- 过程关系：生命周期、孵化、成长/蜕皮等阶段性过程。
- 条件—结果关系：生存条件或身体受压等情境，与存活或通过狭窄空间等能力说明相联系。

### 2. 视觉编码与叙事

- 大型写实蟑螂插画承担主题锚点和解剖参照双重作用。
- 引线将结构标签与身体具体位置绑定，局部放大图补充细节。
- 弧形时间轴建立演化时间纵深；箭头和路径线用于表达行为或过程方向。
- 整体以白底、黑灰文字和棕色主体插画为主，局部浅绿/青色用于辅助强调。
- 整体图与局部放大图形成尺度层级，帮助读者从对象全貌进入器官细节。
- 叙事从标题吸引、演化背景、对象全貌，逐步进入身体机制、生存能力、物种差异和生命周期。

### 3. 单案例可观察到的制作方法

- 以大型主体插画作为全图的知识导航中心。
- 使用引线把文字知识绑定到对象的具体结构。
- 根据关系类型选择图形：时间用时间轴、结构用解剖图、分类用对比图、过程用阶段示意。
- 通过整体—局部尺度切换解释复杂对象。
- 用周边分区承载多种知识结构，并由统一主体与标题维持整体关联。

### 4. 证据边界

- 原图为长幅低分辨率截图，部分微小英文注释、年代、数字和图例不可可靠辨认。
- 可确认有时间、比较和过程信息，但不能据此补写精确统计口径、单位或计算公式。
- 不能把说明性解剖图或行为示意图默认理解为严格比例的统计图。
- 图面没有足够证据证明其使用了 ISO 标准图形体系；应以可辨认的解剖插画、符号、引线和图示为分析对象。

## 案例 003 的初步归纳（单案例观察）

### 1. 数据逻辑与图形组合

本案例围绕跨区域交通网络并置多种数据关系：
- 地理空间关系：国家、城市、港口、铁路节点及线路的位置和连接。
- 路线/网络关系：铁路走廊、海运线路、能源线路及基础设施项目的分布。
- 沿线序列关系：沿铁路线路按地理顺序排列城市、站点和地形变化。
- 地形连续变化：路线里程与地形起伏之间的对应关系。
- 多维风险比较：国家/地区 × 基础设施类别的风险等级。
- 工程流程关系：不同轨距铁路系统之间的转运/换轨处理步骤。
- 运输规格与容量关系：集装箱规格、机车、列车编组及运载数量。
- 时间比较关系：不同运输方案的平均运输天数。

### 2. 视觉编码与叙事

- 中央浅灰地图作为空间总索引，叠加不同颜色/样式的交通与能源线路。
- 顶部及下方黑色连续轮廓将铁路路线转化为地形纵断面。
- 风险比较模块用黄色/灰色条带或楔形表达相对等级；具体语义依赖图例。
- 右上轨距转换图用轴测/透视结构和编号步骤解释工程机制。
- 底部机车、集装箱线框图和重复车厢形态把运输设备与容量转化为可见对象。
- 版面从宏观地图、路线剖面推进到设备细节，形成多尺度视觉叙事。

### 3. 单案例可观察到的制作方法

- 以地图承载宏观空间关系，再把路线细节拆到周边专题图表。
- 将地图与路线纵断面配对：地图回答“线路在哪里”，纵断面回答“沿线经过怎样的地形与地点”。
- 从洲际线路、单条铁路深入到轨距转换设备、集装箱和机车，形成宏观—中观—微观的信息层级。
- 用风险比较补充地图难以直接表达的国家/地区基础设施条件。
- 用轴测图解释抽象工程机制，用重复实体表现运输编组和数量。

### 4. 证据边界

- 图面没有提供足够清晰的完整数据表、单位和方法说明，无法确认风险评分算法、纵断面采样方式、平均运输时间统计口径或集装箱数量计算条件。
- 不得把地形轮廓当作未经验证的精确海拔数据，也不得由示意图自行推导工程参数。
- 风险图、路线天数、机车参数和集装箱数量的具体数值需原始高清资料核验。
- 图面未提供足够证据证明使用了 ISO 标准图形体系。

## 当前阶段性原则（由三个案例支持的初步观察，仍待更多案例验证）

1. 混合型信息图形的“混合”不只是多种图表并排，而是不同数据逻辑、解释性图示、符号系统与视觉叙事在统一主题下协同。
2. 不同数据/知识关系应采用与其结构相匹配的图形语法，不应把所有内容强行转换为同一种统计图。
3. 统一的主视觉结构不一定是主题插画：它可以是对象插画，也可以是地图/空间网络；主视觉承担跨模块的语义或空间索引作用。
4. 重复符号、引线、线路颜色和一致的标签系统可建立跨模块或图文之间的识别关系，但颜色语义必须以对应图例为准。
5. 统计信息与非统计信息可以共同构成叙事，但应保持图例、数据来源、量纲和语义边界清晰。
6. 混合型作品可以采用非线性模块阅读，也可以形成由整体到局部、由宏观到微观的路径；阅读顺序应服务于主题。
7. 地图可作为宏观空间骨架，路线剖面、风险比较和工程示意分别补充空间、条件与机制信息；这些模块应通过地点、路线或统一主题建立可追踪的对应关系。

以上原则由目前三个案例提供初步支持，仍需更多案例检验；后续案例可能补充、修订或推翻其中部分判断。

## 后续案例更新规则

每收到新案例：
1. 保存原始案例图片及单独的案例分析文档。
2. 记录实际使用的统计图形、数据逻辑、计算方式、符号/ISO 图形证据。
3. 分析点、线、面、体、符号、色彩、字体、版式等视觉编码。
4. 分析数据/信息架构与视觉叙事顺序。
5. 与已有案例比较，区分共性、差异和该案例独有的做法。
6. 更新本说明文档中的阶段性原则、方法和适用边界。

> 不以未经案例支持的通用知识替代案例分析；不将单个案例的特征直接推广为普遍规律。
