# CASE-0011 数据字典

## 当前数据状态
- CSV 为字段模板，0 条观测记录。
- 原因：当前用户上传图像分辨率不足以可靠转录所有国家名、菜名和底部统计数字。
- 官方作品说明确认该图收集各国国菜；若无正式国菜，则采用与该地相关的流行菜肴。
- 国家名称字母排序是本案例的主逻辑判断；逐条 A—Z 顺序仍待高清原图核验。

## 字段说明
| 字段 | 类型 | 含义 |
|---|---|---|
| entry_id | string | 国家/地区条目唯一 ID |
| country_name_as_shown | string | 按图面原样转录的国家/地区名称 |
| normalized_sort_key | string | 用于字母排序的规范化键；规则需统一 |
| region_code | string | 国家/地区所属区域代码 |
| map_location_id | string | 地图点位或区域的关联 ID |
| dish_id | string | 代表性菜肴唯一 ID |
| dish_name_as_shown | string | 图面菜肴名称 |
| source_note | string | 图面位置或经核验的来源 |

## 记录与计算规则
1. 最小索引记录单位为国家/地区条目；一道菜与一个国家/地区的对应关系单独记录。
2. 国家名称的排序键与显示名称分开保存，便于处理冠词、标点、别名和不同语言名称。
3. 菜肴与食材为多对多关系，正式数据应另建食材表和菜肴—食材关联表。
4. 目录插画不是频数数据；不可按图标面积或颜色估算数量。
5. 食材占比必须保留分子、分母、单位和统计口径。
