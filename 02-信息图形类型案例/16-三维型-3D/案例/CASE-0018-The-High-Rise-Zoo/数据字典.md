# CASE-0018｜数据字典

## 文件：基础数据集.csv
当前为字段模板，没有作者原始数据或可核实的工程数值。每行表示一个垂直功能层。

| 字段 | 类型 | 含义 |
|---|---|---|
| building_id | string | 建筑方案标识 |
| level_id | string | 功能层唯一标识 |
| level_order | integer | 图面自上而下的层级序号；不代表实际楼层编号 |
| level_name | string | 功能层名称 |
| habitat_type | string | 栖息环境类别 |
| primary_program | string | 主要生态/公共功能 |
| visual_color | string | 图面主要颜色 |
| note | string | 图面观察备注 |
| evidence_status | string | 图面可见/待核验/推断 |

## 数据限制
- 不填入无法辨认的物种名称、数量、面积、层高和建筑参数。
- 动物与植物图符仅作场景识别，不能据图符数量推算真实物种数量。
- 建议未来增加 Entities 与 Cross-level relations 两张关联表。
