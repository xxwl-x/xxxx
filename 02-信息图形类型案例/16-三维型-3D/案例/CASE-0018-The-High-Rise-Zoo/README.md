## 分类理由
图面以一座高层建筑为整体，将屋顶夜行/陆生栖息环境、水体环境、绿地与林地、动物栖息层、鸟类活动层及底部餐饮等功能沿垂直方向展开。读者需要理解建筑整体由哪些上下叠置的功能层构成，因此主导关系是整体—部分及垂直层级。3D是表现方式，不替代五大基础逻辑。
