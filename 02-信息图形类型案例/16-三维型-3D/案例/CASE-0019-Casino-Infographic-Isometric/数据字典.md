# CASE-0019｜数据字典

## 文件：基础数据集.csv
当前为空字段模板；图面没有提供真实运营数据。

| 字段 | 类型 | 含义 |
|---|---|---|
| system_id | string | 整体概念装置标识 |
| module_id | string | 垂直模块唯一标识 |
| vertical_order | integer | 图面自上而下的模块顺序 |
| module_label | string | 图面可辨识的模块标签 |
| activity_type | string | 可辨识的活动类别；不确定时留空 |
| equipment_type | string | 游戏设备/道具类别 |
| module_color | string | 图面主要色彩 |
| annotation_status | string | 已标注/未标注/占位文字 |
| evidence_status | string | 图面可见/推断/待核验 |

## 数据限制
- “Poker Hall 6”“Roulette Hall”“Slot Machine”为图面可辨识标签；未标注模块不得自行补全名称。
- Lorem ipsum为占位文案，不得转录为真实说明。
- 不得根据筹码、轮盘、人物或老虎机插画推算金额、赔率、中奖概率或客流。
- 若记录插画人物数量，必须明确其只是图面对象计数，而非真实人数。
