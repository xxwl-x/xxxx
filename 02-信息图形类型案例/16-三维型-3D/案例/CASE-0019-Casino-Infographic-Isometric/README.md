## 分类理由
画面将一台老虎机作为整体容器，沿垂直方向拆成多个功能模块，并在各模块内部布置桌游、轮盘、老虎机及赌场场景。模块之间具有整体—部分的结构关系，且通过垂直分层呈现，因此基础逻辑主归属为层级型；三维等轴测是主表现形式。
