# CASE-0029｜The ageing problem / The weight problem / NHS Staffing Increases

## 分类
**主表现：08 图片式 Photo-graphic；基础数据逻辑主归属：编目型。** 图面按老龄化、肥胖、NHS人员三个统计专题分组；国别/年份是各专题内部的比较字段。辅助标签：06比较型、01混合型。照片不是单纯背景，而通过裁切蒙版与柱形统计图融合。

## A 基本数据逻辑
最小数据单位为**指标—国家/年份—百分比或人数**。上部“The ageing problem”给出2007年各国65岁以上人口比例；中部“The weight problem”给出成年人肥胖流行率（统计年份在当前截图中未清晰显示）；下部“NHS Staffing Increases”对照1998与2008人员总数。主题不同、分母不同，不应跨主题进行直接加减。

## B 统计图形与计算
- 老龄人口：国家类别横向排列、柱形高度表示比例，黑白老年人物照片经分段蒙版裁切成为条形填充。可辨Japan 28、Italy 26、Germany 25等百分比。
- 成年肥胖：按国家排列的照片填充矩形柱形，数值如UK 24.0%、US 34.3%；英国柱以黄色高亮。
- NHS：1998年583,742、2008年760,886的红色圆形数字单元，中间30.3%增长标注。按照(760886−583742)/583742×100%≈30.3%。但**未证明两个圆的面积严格与人员总数成比例**，不能凭圆直径测量人员数量。
- NHS内还有Doctors、Nursing staff、NHS infrastructure等细分文字，截图小字需核验。

## C 视觉编码
|视觉通道|语义|
|---|---|
|条形高度|国家比例的定量编码|
|照片剪裁|柱形内部的议题情境（老龄、体重），不是额外统计变量|
|国家标签|分类轴|
|网格和分隔线|界定每个国家柱形与图片片段|
|数字标签|提供精确百分比与人员总量|
|红色圆形|突出NHS人员规模对照；不擅自解释为严格比例面积|
|黄色局部强调|突出英国肥胖数据，不自动表示危险等级|
|医疗十字图符|识别医疗系统相关模块|
风险：摄影层可能干扰统计轮廓/文字对比；条形大小与照片内容易被混读；跨国统计口径可能不同。

2. CountryValues表（indicator_id、country、year、value、unit）。

4. PhotoEncoding表（chart_id、photo_id、mask_geometry、highlight_reason）。
本次录入可辨国家百分比及人员总量，肥胖指标的year留空；未补造NHS各职业细项。

## E 视觉叙事
第一段用老年群像与各国数据表达老龄化挑战；第二段以身体摄影和国家肥胖比例展示另一类公共健康风险；第三段将话题转向NHS人员增长。构成“人口结构与健康问题→医疗资源”的新闻议题并置，但**没有因果模型证明老龄化/肥胖导致NHS扩员**。

## 可复用方法
照片蒙版条形图将情境融入统计编码；确保每根柱子的底线、类别、数值尺度不被摄影破坏；主题之间明确单位/分母；数字覆盖在复杂图像上时须保证清晰；编辑故事≠因果证据。
