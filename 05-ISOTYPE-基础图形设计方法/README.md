# 05｜ISOTYPE 基础图形设计方法

ISOTYPE（International System of Typographic Picture Education）是一种图像语言、图符编码与信息转译的方法体系，**不是**五大基础信息组织逻辑中的第六类，也不是02案例库的市场化表现类型之一。

## 分类规则
- **01**：识别作品的基础信息逻辑（编年、层级、编目、字母表、地理）。
- **02**：识别市场表现形式标签与正式CASE归档。
- **03**：统计图形与计算方法。
- **04**：主题信息图形设计工作流程。
- **05**：ISOTYPE图像语言、标准化图符、重复单位编码与信息转译方法。

一个案例的主档案仍只在02中保存一次；若符合ISOTYPE研究条件，在05通过链接交叉引用，不复制同一个CASE。
