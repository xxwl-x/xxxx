# 01｜前期调研

## 目标
明确XXX选题的研究问题、受众、场景、项目边界与产出条件。**此阶段不提前决定信息图形风格。**

## 工作步骤
1. 定义选题：XXX研究的对象、地域、时间、主要问题和为什么值得可视化。
2. 受众：年龄、知识背景、阅读任务、阅读媒介；不要根据外貌或身份预设理解力。
3. 参考研究：行业研究、公开信息图案例、竞争作品、文献与访谈线索。记录每项出处。
4. 资源和约束：工期、数据是否可得、图片使用权限、版面规格、输出渠道、无障碍需求。
5. 形成研究假设和待证实问题清单。

- [调研简报模板](./调研简报模板.md)
- [参考案例与来源清单](./参考案例与来源清单.csv)

## 阶段门槛
研究问题明确，至少记录一个可追溯来源；缺证据的问题显式标为“待调查”，不得编造调查结果。
