## 操作原则
**第一，先判断信息逻辑，再决定表现形式与风格。** 02分类标签、平面／摄影表现和统计方法是不同的决策层，不应混同。第二阶段需把大模型给出的方案、适用数据、理由、风险与人工确认结果记录下来。

**第二，基础数据集一格一值。** 单元格中可以放一个类别名、一个数量、一个日期、一个图片资产ID、一个完整文本单位；但不能放多个独立属性。经纬度分列，数量与单位分列，多值关系独立建表。第五阶段才组合字段形成叙事视图，不反向修改原始数据。

**第三，第六阶段偏重设计表达。** 图形编码的统计意义必须准确，但允许结合摄影、插画、字体表现、色彩、网格、Gestalt知觉组织及ISOTYPE标准化图符实现多种创作方向。

**第四，参考而不重复存档。** 五大基础逻辑参考[01](../01-信息图形数据逻辑/)，17种表现标签及案例参考[02](../02-信息图形类型案例/表现形式标签索引.md)，统计方法参考[03](../03-统计图形分析/)，知觉组织参考[04-Gestalt](../04-Gestalt-格式塔视觉组织原则/README.md)，图符转译参考[06-ISOTYPE](../06-ISOTYPE-基础图形设计方法/README.md)。
