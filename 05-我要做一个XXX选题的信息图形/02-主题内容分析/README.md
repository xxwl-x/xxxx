# 02｜主题内容分析与大模型协同分类

## 目标
同大模型讨论XXX的本质数据关系、可用图表与视觉表现形式，先理解信息，再选择设计方案。**此阶段的分类是建议，必须随实际数据证据修订。**

## 决策分层（不得混为一类）
1. **基础数据逻辑（01）**：在编年、层级、编目、字母表、地理五种中选一个主归属，另记录复合关系。依据是数据字段与记录间的真实关系，而不是图面外观。
2. **市场表现标签（02）**：参考[17种表现形式](../../02-信息图形类型案例/表现形式标签索引.md)，选主标签及辅助标签。如词云、文字/列表型、图片式、单一图表、混合型、比较型、地图型、流程图等。标签说明展示方式，不替代数据结构。
3. **视觉风格**：平面、摄影、插画、手绘、三维、编辑设计、极简等；可与任何基础逻辑组合。
4. **统计图形/图像语言**：折线、柱形、散点、地图、词云、象形图，或[ISOTYPE](../../06-ISOTYPE-基础图形设计方法/README.md)的标准化图符方法；统计语义单独检查。
5. **视觉知觉**：用[Gestalt](../../04-Gestalt-格式塔视觉组织原则/README.md)复核分组、连续、背景与关系误读。

## 与大模型的工作方式
- 先提供主题、研究目标、受众、样例字段、时间/地理范围与数据可用性。
- 要求至少给出2—3种可行设计方向，分别说明基础逻辑、表现标签、视觉风格、图表选择、适用数据、优点、风险和不推荐原因。
- 对“编年还是编目”应给出可检查的依据，比如是否有事件先后、对象分类、位置关系与主导阅读轴。
- 分类决定写入[分类决策记录](./分类决策记录.md)，不能把模型回答当作已证实的数据事实。
