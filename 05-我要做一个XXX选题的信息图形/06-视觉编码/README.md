# 06｜视觉编码与设计表达

## 定位
这一阶段**偏重设计表达**：将叙事模块及其字段转换为具有信息准确性、审美完整性、表现特色的画面。不是简单决定使用柱形图或地图，而是构筑全套视觉语法。

## 设计决策层
1. **信息层**：每个模块的主命题、次级信息、数据证据、注释和来源。
2. **统计层**：按数值类型选择柱、线、点、面积、比例符号、网络、地图等；确定比例尺、基线、排序、单位与图例。
3. **视觉编码层**：点、线、面、体、空间、方向、颜色、大小、形状、纹理、符号、照片和文字各自承担的语义。
4. **视觉组织层**：版式网格、留白、视觉节奏、分组与阅读路径，引用[Gestalt原则](../../04-Gestalt-格式塔视觉组织原则/README.md)。
5. **设计风格层**：平面、照片、插画、三维、手稿、编辑设计、极简等；决定形式语言、材质、品牌适配性。
6. **图像语言层**：需要[ISOTYPE](../../06-ISOTYPE-基础图形设计方法/README.md)时，定义每图符的单位、重复数量、类别编码与图例，避免把装饰图标误作为定量数据。

## 阶段产物
视觉风格板、模块草图、版式网格、字体层级、色板、图片选用规则、统计图示意、图符系统、视觉编码映射表、图例与无障碍审查记录。草图应与使用的数据字段、版本和来源关联。

## 审查门槛
任何大小、长度、面积、颜色变化若被观众理解为数据变化，必须明确其所映射的字段与计算规则；纯装饰需能和统计编码区分。
