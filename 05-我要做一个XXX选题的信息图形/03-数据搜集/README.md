# 03｜数据搜集

## 三类数据来源
### A 公用数据集
政府开放数据、官方统计、研究机构及具有明确发布许可的数据仓库。记录URL、发布方、许可、版本、访问日期、样本和统计口径；开源不等于可任意商用。

### B 文本文献
书籍、论文、报告、新闻、访谈或档案。保留完整引用、段落位置与引文边界；提取出的事件/观点与原文语句建立来源映射。

### C 自建数据集
调查、田野观察、人工编码、采访记录、摄影采样等。明确采集流程、样本方案、知情同意、个人隐私、图像授权和质量控制。原始材料与清洗数据分离。

数据可为数值、类别、时间、地理、文本、图片资产引用等；图片文件保存在素材目录，表中只用一项资源ID或URI引用，不把复杂图片硬塞进CSV字段。

## 交付
每项来源均有ID、权限状态、出处、引用位置和数据质量说明；原始数据不直接在设计草稿中手工改写。
