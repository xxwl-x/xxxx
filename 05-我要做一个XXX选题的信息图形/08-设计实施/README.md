# 08｜设计实施

## 目标
把已完成数据与视觉方案落实为可交付的信息图形，并保证**数据、表达、版权和版本可追溯**。

## 步骤
1. 设计规格：尺寸、版式、印刷/数字媒体、分辨率、适配范围。
2. 设计系统：字体、配色、图符、版式网格、组件与图库。
3. 制作分模块图形：绑定已确认的数据视图，避免手工抄错。
4. 视觉整合：图表、插画、摄影、文字、来源与信息层次统一。
5. 校对：数值、单位、时间、名称、坐标、图例、版权和引用。
6. 信息测试反馈：按第07阶段确认后的办法收集问题并迭代；在其尚未定义时记录其他已实际执行的常规测试，不冒称“轮盘测试”已完成。
7. 交付：最终导出、可编辑源文件、数据快照、修改日志与授权证明。
8. 复盘：方法效果、误读、可复用视觉语言与案例知识回写。

## 交付门槛
所有图中的数字、位置、标签能追踪到源字段或清楚标注为设计示意；原图与素材有可使用的许可；最终版本有明确责任人和校对日期。
