## 01｜唯一的五种基础信息逻辑
每件案例必须根据主导的信息关系选择一个基础归属：
1. [编年型](./01-信息图形数据逻辑/01-编年型信息图形概念定义.md)：顺序、阶段、进程与状态变化。
2. [层级型](./01-信息图形数据逻辑/02-层级型信息图形概念定义.md)：上下位、包含、从属、主次或等级。
3. [编目型](./01-信息图形数据逻辑/03-编目型信息图形概念定义.md)：对象分类、类别归属与并列比较。
4. [字母表型](./01-信息图形数据逻辑/04-字母表型信息图形概念定义.md)：按名称或标准化索引键检索。
5. [地理图形型](./01-信息图形数据逻辑/05-地理图形信息图形概念定义.md)：位置、区域、距离、邻接与空间流动。

五种基础逻辑是唯一的基础类型学，不因图形外观或表现形式增加第六类。作品可以组合局部关系，但应明确主导关系；证据不足时标记待分类。

## 案例驱动的知识迭代规则
1. 核验原图、来源、日期与版权状态。
2. 区分图面事实、计算结果、设计解释和待核验内容。
3. 判断五种基础逻辑主归属，再选择主表现标签及辅助标签。
4. 完成 A–E 五维分析，并建立可追溯的数据表与数据字典。
5. 与同类案例比较后，才把重复出现的特征提炼为方法。
6. 将有案例证据支持的结论回写 01 理论、02 标签说明和案例索引。

不编造不可辨认的数字、来源、统计口径或作者制作步骤。抽象示例必须标注为示意数据。第三方图片只有在获得适当权限后才能提交原图文件；否则保存来源链接和权利说明。
