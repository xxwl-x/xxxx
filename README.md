# 信息图形知识库

本仓库分为两个部分，严格按照用户指定的分类与资料来源规则维护。

## 01-信息图形数据逻辑

该目录固定包含 5 份 Markdown 定义文档：

1. [01-编年型信息图形概念定义](./01-信息图形数据逻辑/01-编年型信息图形概念定义.md)
2. [02-层级型信息图形概念定义](./01-信息图形数据逻辑/02-层级型信息图形概念定义.md)
3. [03-编目型信息图形概念定义](./01-信息图形数据逻辑/03-编目型信息图形概念定义.md)
4. [04-字母表型信息图形概念定义](./01-信息图形数据逻辑/04-字母表型信息图形概念定义.md)
5. [05-地理图形信息图形概念定义](./01-信息图形数据逻辑/05-地理图形信息图形概念定义.md)

每份定义文档按以下五个方面分析：
- A. 基本的数据逻辑
- B. 使用的统计图形、统计方式和计算方式
- C. 视觉编码（点、线、面、体、符号、色彩等）
- D. 数据/信息架构
- E. 视觉叙事架构

**重要：** 五份定义文档不保存图片案例，只通过 Markdown 文本链接连接到 `02-信息图形类型案例` 中的相关案例。所有结论、原则和方法必须根据用户提供的案例图分析总结；未收到案例图前不预设结论。

## 02-信息图形类型案例

该目录只按以下三类组织：

## 案例驱动的迭代规则

- 用户提供案例图后，先分析图像中的具体信息和视觉证据。
- 再更新对应案例记录与说明文档。
- 随着案例增多，持续归纳和修订内容、原则与方法。
- 不以未经案例支持的通用知识替代用户要求的案例分析。
