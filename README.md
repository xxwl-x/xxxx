# 信息图形知识库

用于系统整理信息图形的数据逻辑、类型方法、视觉编码、信息架构、视觉叙事与典型案例。

## 目录结构

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/)：五类信息图形的概念定义与方法框架。
- [02-信息图形类型案例](./02-信息图形类型案例/)：按类型收集、整理和分析参考案例。

## 类型定义文档的统一框架

每种类型均从以下五个方面展开：

1. **基本的数据逻辑**：核心数据结构、关系及适用条件。
2. **统计图形与计算方式**：借用的统计图形、统计方法和计算逻辑。
3. **视觉编码**：点、线、面、体、符号、色彩等视觉变量的映射与优化。
4. **数据/信息架构**：信息分类、组织、层级及阅读路径。
5. **视觉叙事架构**：主题建立、重点突出、关系表达与叙事顺序。

## 案例分析规范

每个案例尽可能记录：案例名称、设计者/机构、发布时间、原始链接、信息主题、数据结构、图形方法、视觉编码、信息架构、叙事方式及可借鉴之处。无法核实的内容应明确标注为“待核实”。

## 维护约定

- 文档统一使用 UTF-8 编码的 Markdown。
- 文件名使用数字序号，便于排序。
- 类型定义与案例分析分开维护。
- 案例来源尽量指向原始发布页面。
