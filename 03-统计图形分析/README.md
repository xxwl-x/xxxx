# 03｜统计图形分析

本目录研究统计图形如何将数据字段、统计计算和视觉变量对应起来。它回答“使用什么数据、如何转换、用什么图形表达”，不承担基础类型学分类。

## 与其他目录的关系
01 判断数据/信息的主导组织逻辑；02 存放案例并标注表现形式；03 分析案例使用的统计图形、计算方法和数据要求；04 将数据与叙事、视觉编码整合为主题设计流程。

## 统计图形研究维度
每种图形建立独立说明时，统一记录：图形要回答的问题与适用数据类型；最小数据表结构、字段类型与记录粒度；数据清理、聚合、转换与计算公式；视觉通道映射；比较基准、刻度、单位与图例；适用条件、局限和误用风险；对应案例及来源。

## 图形类别导航
- 比较类：条形图、柱形图、点图、哑铃图、坡度图。
- 时间类：折线图、面积图、时间轴、甘特图。
- 构成类：堆积条形图、百分比堆积图、环图/饼图、马赛克图。
- 分布类：直方图、箱线图、小提琴图、散点分布。
- 关系类：散点图、气泡图、网络图、弦图。
- 层级类：树图、矩形树图、旭日图、冰柱图。
- 地理类：分级设色地图、比例符号地图、流向图、格网图。
- 多变量类：热力矩阵、平行坐标、小倍数图、雷达图。

以上为待研究导航，不代表每种图形都已建立完整规范。流程图、解剖标注图等非统计图形，应标记为示意/结构表达，不误称为统计图。

## 数据与计算约束
先确认字段含义、单位、粒度、缺失值和分母，再选择图形。同一图形中的数据需具备可比较的统计口径。面积、角度、长度和颜色映射必须可解释并提供图例。累计值、比例、频数、均值和指数不能混用。无法从图片复原的数据标记不可还原。
